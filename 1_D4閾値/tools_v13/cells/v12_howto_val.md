# 正当化結果の読み方

- (B) が PASSED なら、検査した軌道上で twisted-frame エンジンの全ての測定確率と論理忠実度が、ゲージ配位基底の密な状態ベクトル計算と一致しています（丸め誤差 ~1e-7 程度）。軌道ごとの一致なので、標本の一致より強い検査です。ただし全ての故障列を網羅したものではありません。
- (C) の図（`_C.png`、論理セクター `r` と `rgb` のパネル）で、赤（Exact）と青（main）の曲線が誤差棒の範囲で重なれば、メインコードの論理エラー率は $L=3$ で厳密計算と一致しています。twisted-frame エンジンの更新則は $L$ に依存しない代数的な恒等式ですが、ビットの語境界・幾何・復号グラフなど $L$ に依存する実装経路もあるので、$L=3$ の一致は大きい $L$ への適用を**支持する数値的な証拠**であって、全てのサイズでの実装の正しさの証明ではありません（密な計算は $L=5$ では $2^{73}$（`r`）〜$2^{75}$（`rgb`）成分で実行不能なため、$L=3$ で確認します）。研究 2 の正当化（Pauli proxy と twisted-frame 系の独立なエンジンの一致）も間接的な裏付けです。
- 灰色（旧研究のサロゲート。`VCFG["run_old_surrogate"]=True` のときだけ描かれる）の曲線は、初期状態・終端・雑音の集約・失敗判定が異なる別モデルの参考です。非可換性の効果の切り分けは、メインコードの `dressing_treatment` による対照実験で行います。
- 厳密性の前提（= メインでも同じ理想化）: 初期状態はノイズのない符号状態、終了時は完全な測定ラウンド（非自明な X ループは flux 側の論理エラー）、circuit-level はネイティブ CCZ ゲート（CCZ の T 分解内部の故障は含まない）。
