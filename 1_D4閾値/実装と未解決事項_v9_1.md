## 1. (E) Pauli proxy エンジンによる大きい $L$ での相互検証（引き継ぎ §3.2 の 1）

### 1.1 方式

研究 2・3 と同じ Takada–Bartlett–Williamson の Clifford-stabilizer simulation で、研究 1 の記憶実験をそのまま表す独立なエンジン（`ProxyTorusBackend`）を作った。

* 物理状態を $E\,C\,|\mathrm{frame}\rangle$ と書く。$C=\mathrm{diag}((-1)^{\phi_0})$、誤りフレーム $E=X^x\mathrm{diag}(\omega^\gamma)$（研究 2 の `ErrorFrame` と同じ代数。CZ 型・S 型の成分も持つ）、$|\mathrm{frame}\rangle$ は Stim の Pauli 安定化子状態。初期の frame は平坦配位（3 色の星と `logical_colors` の $x$ 方向ホロノミー）の一様重ね合わせで、$C|\mathrm{frame}_0\rangle$ がメインと同じ符号状態（ホロノミーの代表元で $\phi_0=0$、密な計算と同じ規約）。
* dressed チェック $G=X^s\mathrm{CZ}^{\rm pairs}$ は、$E$ で共役し CZ 因子を Pauli proxy（恒等）に置き換えた Pauli 演算子として測る。平坦部分空間上で $C^\dagger X^s\mathrm{CZ}\,C=X^s$（twisted frame が使うのと同じ恒等式 $\phi_0(b+s)+\phi_0(b)=q_s(b)$）なので厳密。研究 2 の条件 C1 に相当し、新しい仮定は加えていない。
* 最終の忠実度は、$X$ フレームを除いた後に $F(\delta)=|\langle\mathrm{frame}_0|\bar Z^\delta\,\mathrm{diag}(\omega^\gamma)|\mathrm{frame}\rangle|^2$ を、Stim の状態の複製に対する frame$_0$ の生成元の逐次の事後選択で求める（全ての復号器の補正 $\delta$ について）。
* twisted frame（アフィン部分空間と二次形式）とは状態の表し方を全く共有しない。共有するのは幾何・プロトコル・JIT/電荷の復号器・回路レベルの故障表（故障の合成は `TFBackend._compose` と同じ）。故障表のゲート単位の正しさは $L=3$ の密な計算 (B) が確認する。

### 1.2 結果（`v9_1_検証ログ/d4_v9_1_proxy_crosscheck_L3-9.csv`）

twisted frame が結果を決め（ロックステップ）、Pauli proxy が同じ測定の確率を独立に計算して照合する。許容差は $10^{-6}$（どちらも厳密な 0, 1/2, 1 なので、実際の差は全て 0）。

| 雑音 | $p$ | $L=3$ | $L=5$ | $L=7$ | $L=9$ |
|---|---|---|---|---|---|
| 符号容量型 | 10% | 2000 軌道、ランダム 1,924 | 1000、1,186 | 400、754 | 200、496 |
| 現象論的 | 3% | 2000、9,294 | 1000、24,832 | 400、28,604 | 200、32,456 |
| 回路レベル `uniform` | 0.4% | 2000、17,966 | 1000、41,934 | 400、46,700 | 200、51,491 |
| 回路レベル `legacy_v7` | 0.4% | 2000、17,789 | 1000、42,393 | 400、46,510 | 200、51,474 |

合計 14,400 軌道、dressed 測定 約 530 万回（うちランダム 415,803 回）で、**全ての測定確率と、flux 成功の軌道の全ての補正 $\delta$（8 通り）に対する最終忠実度が完全に一致**（最大差 0）。手元の CPU で合計 約 14 分。

**負の対照**（`proxy_negative_controls.log`）：Pauli proxy 側の Pauli dressing を外す／誤りフレームの CZ 成分を落とすと、最初の数軌道で不一致が出る（検査が空振りでないことの確認）。補助量子ビット–データの CZ 故障の経路を壊しても検出されないが、これはその故障を生む位置が回路に無いため（故障表で 0 件。§3 の原稿の修正にも反映）。

**意味**：v9 までの正当化は $L=3$（密な状態ベクトル）だけで、$L\ge5$ は「更新則が $L$ によらない」という議論に頼っていた。(E) により、ビットの語境界・幾何・復号グラフなど $L$ に依存する経路を含めて、$L=5,7,9$ の本番の標本化が独立な厳密エンジンと軌道ごとに一致することを示した。研究 1 の twisted frame と研究 2・3 の Pauli proxy は、同じ記憶実験で直接一致する（v9 までは研究 2 の正当化を介した間接的な一致だった）。

## 2. 電荷復号器の事前分布 $\kappa_{\rm dec}$ の走査（R1-7、正当化 (D)）

v9 で回路レベル雑音の定義を `uniform` に変えたが、$\kappa_{\rm dec}$ は v7（`legacy_v7`）で選んだ 0 のままだった。正当化 (D) の走査（本番と別の seed、各点 $2\times10^4$ ショット）を実行した。

| 雑音 | $p$ | $\kappa_{\rm dec}$ ごとの charge 失敗率（$L=7$） | 判断 |
|---|---|---|---|
| 符号容量型 | 9.5% | 0: 0.450、0.25: 0.442、0.5: 0.441、1.0: 0.442 | **0.5 のまま**（0.25–1.0 は誤差内で同じ、0 より良い） |
| 現象論的 | 2.1% | 0: 0.169、0.1: 0.169、0.25: 0.191 | **0 のまま** |
| 回路レベル `uniform` | 0.2% | 0: 0.115、0.1: **0.102**、0.25: 0.105、0.5: 0.111 | **0.1 に変更** |

回路レベルは $L=7,9$、$p=0.15\%,0.25\%$ でも確認した（`d4_v9_1_decoder_kappa_check_circuit_level_uniform_L7-9.csv`）：$L=9$, $p=0.15\%$ で $\kappa_{\rm dec}=0$: 3.33% [3.09, 3.59] → 0.1: 2.79% [2.57, 3.03]、$L=9$, $p=0.25\%$ で 26.8% → 25.3%、$L=7$ でも全ての $p$ で 0.1 が最小。$L=3,5$ でも 0 より良い（0.1 と 0.25 は誤差内で同じ）。物理（標本化）は変わらず、復号器の重みだけが変わる。

* 実装：`CFG["tf_decoder_kappa"]` に `"circuit_level/uniform": 0.1` を加え、回路雑音の定義ごとの値があればそれを使う（`decoder_kappa`）。`legacy_v7` は従来どおり `"circuit_level": 0.0`（v7 の結果は変わらない）。対照実験（none, kappa_injection）も同じ復号器を使う。
* 交点への影響（試行、$L=3,5,7$、各点 4,000 ショット、`pilot_circuit_level_uniform_kappa0.1_L3-7_4000shots.csv`）：$L=3$–5 が 0.219% → **0.159%**、$L=5$–7 が 0.197% → **0.207%**。$L=3$ の曲線が最も大きく下がるので $L=3$–5 の交点が下がった（$L=3$ は復号器の事前分布に最も敏感）。より良い復号器で小さい $L$ の交点が下がるのは矛盾ではなく、漸近的な性能は大きい $L$ の失敗率で判断する（v7 からの規則「最大の $L$ で最小」）。本番の推奨範囲を 0.12–0.30% に広げた。
