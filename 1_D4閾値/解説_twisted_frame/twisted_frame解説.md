# twisted frame の原理 — D4 符号の測定を厳密かつ高速に追いかける方法

（2026-11-12。研究 1 のシミュレーションの中核の解説。英語版 `twisted_frame_explained.tex` は同じ内容に図を加えたもの。式の証明は研究 1 の原稿 `../../論文草稿/研究1_原稿_v12/main_v12.tex` §4 の命題）

「twisted frame」はこの研究で付けた名前で、先行研究の用語ではない（§8）。

---

## 0. 一言でいうと

D4 符号の量子状態は、指数的に大きなベクトルとして持つと手に負えない。しかし誤りと測定を何回くり返しても、状態は常に

> **「ある連立一次方程式（mod 2）の解の集合」の上に、「2 次式で決まる ± の符号」と、最初から決まっている「3 次式の符号」を載せたもの**

という形に収まる。3 次式の部分は最後まで変わらず、計算する必要もない。変わるのは 1 次方程式と 2 次式だけなので、0 と 1 の小さな行列の計算で、状態を**近似なしに**追いかけられる。これが twisted frame である。

---

## 1. 何を計算したいのか

研究 1 は D4 符号の「記憶実験」をシミュレーションする。論理情報を符号化した状態を用意し、

1. 物理量子ビットにランダムな誤り（雑音）が入る、
2. 符号の検査（スタビライザ）を測って誤りの手がかり（シンドローム）を得る、
3. 復号器が誤りを推定して直す、

を何ラウンドもくり返し、最後に論理情報が壊れていないかを調べる。これを $10^5$ 回ずつ、いろいろな大きさ $L$ と誤り率 $p$ でくり返して、失敗率の曲線から閾値を求める。必要なのは「雑音の 1 つの実現に対して、どの測定結果がどの確率で出るか」を正しく計算する道具である。

### 1.1 普通の方法が使えない理由

| 方法 | 問題 |
|---|---|
| 状態ベクトルをそのまま持つ | $L\times L$ のトーラスには $n=9L^2$ 個の量子ビットがあり、振幅は $2^n$ 個（$L=3$ でも $2^{81}$）。誤りの無い配位に限っても $L=3$ で $2^{27}\approx1.3$ 億が限界で、$L=5$ は $2^{75}$ になり不可能 |
| 安定化子シミュレータ（Stim など） | 検査演算子が「Pauli 演算子の積」のときだけ使える。D4 符号の X 型検査は Pauli に CZ が付いた非 Pauli の演算子で、測定回路には CCZ が入る |
| 旧研究の近似（サロゲート） | 検査を CZ の付かない Pauli 検査に置き換え、CZ の効果を独立な雑音として足していた。後で述べる「検査どうしが非可換になって測定がランダムになる」効果を表せない |

### 1.2 D4 符号の何が難しいのか

* **検査に CZ が付いている**。頂点ごと・色ごとの X 型検査は $S = X^{s}(-1)^{q(a)}$ と書ける。$X^{s}$ は 6 個の量子ビットの X、$(-1)^{q(a)}$ は 2 個の CZ が作る符号で、$q$ は 2 つのビットの積の和（2 次式）である。
* **誤りがあると検査どうしが非可換になる**。誤りの無い状態では全ての検査が可換だが、X 誤りが「フラックス」を作ると、色の違う検査の組が反可換になる。すると検査 $S_1$ を測ってから $S_2$ を測り、また $S_1$ を測ると、$S_1$ の結果は 1/2 の確率でしか再現しない。結果は確率的で、「誤り → シンドローム」が決定的に決まる通常の誤り訂正の世界とは違う。
* **フラックスを直した後にも、CZ 型の「残り物」が残りうる**。X 誤りとその補正が閉じたループを作っても、それが検査の積でなければ、状態に CZ 型の誤りが残り、別の色の検査の結果をランダムにする。

これらを近似なしに扱うのが目的である。

## 2. 準備：0 と 1 の言葉で状態を書く

* **計算基底＝ビット列**。各量子ビットを 0 か 1 にした基底状態 $|a\rangle$ を、長さ $n$ のビット列 $a$ で表す。D4 符号では量子ビットが格子の辺 × 3 色に並ぶので、$a$ は「各辺・各色に 0/1 を書いた配位」（ゲージ場の配位）である。
* **平坦な配位**。各三角形・各色で、3 辺のビットの和（mod 2）が 0 の配位を**平坦**という。和が 1 の三角形が「フラックス」（X 誤りの痕跡）。Z 型検査はこの和を測る。
* **符号状態**。誤りの無い D4 符号の状態は
  $$|\psi_0\rangle=\sum_{b\in C_0}(-1)^{\phi_0(b)}\,|b\rangle$$
  と書ける。$C_0$ は平坦な配位（の、ここで扱う論理セクター）の集合、$\phi_0(b)$ は 3 色のビットの積から作る **3 次式**（cup 積）で、これが「twisted（ねじれた）」ゲージ理論のねじれにあたる。トーリック符号なら符号なしの一様な重ね合わせで、D4 符号はそこに 3 次の符号が付いている。

**$C_0$ は連立一次方程式の解の集合**である（平坦＝三角形ごとの和が 0、という一次の条件）。だから $C_0$ の元は少数の座標 $t$ で $b=Mt$ と書ける（頂点ごとの値 $\mu$ と、トーラスを一周する向きのホロノミー $h$。$k=3L^2$ 個の 0/1）。$L=9$ でも $k=243$ で、$2^{729}$ 個の振幅とは比べものにならないほど小さい。

### 2.1 鍵になる事実：安定化子状態は「アフィン集合 ＋ 2 次の符号」

量子計算のシミュレーションでよく知られた事実として、**安定化子状態**（Clifford 回路で作れる状態）は全て

$$\psi(a)\ \propto\ i^{\ell(a)}(-1)^{Q(a)}\,\mathbb 1[a\in A]\qquad(A\text{ はアフィン部分空間、}Q\text{ は 2 次式})$$

の形に書ける（Dehaene–De Moor の標準形）。Stim などが速いのは、この形を行列で持てば済むからである。D4 符号の状態は 3 次の符号 $\phi_0$ を持つので安定化子状態ではない。ここで次の観察が効く。

## 3. twisted frame の表現

1 ショットの状態を、次の 3 つの部品で**厳密に**表す。

$$\boxed{\ \psi(a)\ \propto\ (-1)^{\phi_0(b)+Q(b)}\ \mathbb 1[b\in B],\qquad b=a+x\ }$$

| 部品 | 意味 | 持ち方 |
|---|---|---|
| $x$（X フレーム） | これまでに起きた X 誤りと X 補正の累積。「状態を $x$ だけずらして見る」ための帳簿 | 長さ $n$ のビット列 |
| $B$ | いま重ね合わせに含まれている平坦な配位の集合（$C_0$ の中のアフィン部分空間＝連立一次方程式の解） | 方程式の係数行列（行簡約した形、最大 $k$ 行） |
| $Q$ | 雑音と測定で後から付いた符号。**2 次式** | $k\times k$ の 0/1 行列と 1 次の係数 |
| $\phi_0$ | 最初の符号状態の 3 次の符号 | **持たない**（一度も計算しない） |

名前の由来：**twisted** は 3 次の符号 $\phi_0$（ねじれたゲージ理論）から、**frame** は X 誤りを記録する Pauli frame（Stim などでも使われる考え方）から取った。

### 3.1 なぜ $\phi_0$ を計算しなくてよいのか

検査 $S$ は符号状態を変えない（$S|\psi_0\rangle=|\psi_0\rangle$）。これを配位ごとに書くと、どの平坦な $b$ についても

$$\phi_0(b+s)+\phi_0(b)=q(b+s)$$

が成り立つ（$s$ は検査が動かす量子ビット、$q$ はその CZ の 2 次式）。シミュレーションで必要になるのは、いつも「$b$ と $b+s$ の振幅の比」、つまり $\phi_0$ の**差**だけで、それは 2 次式 $q$ で置き換えられる。3 次式そのものは最後まで登場しない。

## 4. 操作ごとの更新

| 操作 | 更新 | 計算の中身 |
|---|---|---|
| X 誤り・X 補正 | $x$ のビットを反転 | 1 ビット |
| Z 誤り | $Q$ に 1 次の項を足す（$(-1)^{a_q}$ を掛けることに当たる） | 1 行の XOR |
| CZ（回路レベルの故障など） | $Q$ に 2 次の項を足す（$(-1)^{a_ia_j}$） | 行列の 2 列・2 行の XOR |
| Z 型検査の測定 | 結果は $x$ だけで決まる（$B$ は平坦なので、フラックスは全て $x$ にある） | 3 ビットの和 |
| dressed X 検査の測定 | 下の 2 つの場合 | 行列の数行の演算 |

### 4.1 dressed 検査の測定：2 つの場合

検査 $S=X^s(-1)^q$ を測るとき、まず次の **1 次関数**を作る。

$$f(b)=q(b+s+x)+q(b+s)+Q(b+s)+Q(b)$$

これは「$b$ における $S\psi$ と $\psi$ の比の符号」で、$q$ と $Q$ が 2 次式なので、差を取ると 1 次式になる。$q(b+s+x)+q(b+s)$ の項は、X フレーム $x$ が CZ に当たって生じる Z 型の効果（Pauli dressing）で、CZ 型の残り物もここに現れる。

* **場合 (i)：$s$ が $B$ の方向に含まれる**（検査が動かす向きに、$B$ が「閉じている」）。
  * $f$ が $B$ の上で定数なら、結果は**確定**（その定数）。
  * 定数でなければ、結果は**確率 1/2**。出た結果 $m$ に合わせて $B$ を $\{f=m\}$ に制限する（重ね合わせが半分になる）。
* **場合 (ii)：$s$ が $B$ の方向に含まれない**（前の測定が、検査の動かす向きに $B$ を絞ってしまっている）。
  * $B$ と $B+s$ は重ならないので、結果は**確率 1/2**。
  * $B$ を $B\cup(B+s)$ に**広げ**、$B+s$ の側にだけ符号 $(f+m)$ を足す（$Q$ に 2 次の項が 1 つ増える）。

どちらの場合も、状態は「アフィン集合 ＋ 2 次の符号 ＋ 固定の 3 次の符号」の形に戻る（これが原稿の命題）。結果の確率は必ず 0、1/2、1 のどれかになる。

**非可換性はちょうど場合 (ii) である**。フラックスがある状態で検査 $S_1$ を測ると、場合 (i) で集合 $B$ が $S_1$ の条件で絞られる。次に $S_1$ と反可換になった検査 $S_2$ を測ると、$S_2$ は $S_1$ が絞った向きに配位を動かすので場合 (ii) になり、1/2 で結果が出て $B$ が広がる。もう一度 $S_1$ を測ると、今度はその向きが絞られていないので、また 1/2 になる。こうして「$S_1 → S_2 → S_1$ で $S_1$ が再現しない」ことが、特別な処理なしに自動的に出てくる。

### 4.2 1 ショットの流れ

1. 初期状態：$x=0$、$B=C_0$（全ての平坦な配位）、$Q=0$。3 色の論理ホロノミーの 8 通りの重ね合わせ。
2. 各ラウンド：雑音（$x$ と $Q$ を更新）→ Z 型検査（$x$ から読む）→ 実時間のフラックス補正（$x$ を更新）→ dressed 検査を色の順に測る（§4.1）。
3. 終了処理：残ったフラックスを閉じ、$x$ を検査の積で取り除き、完全な測定を 1 ラウンド行う。フラックスが無ければ全ての検査が可換なので、ここで状態は「符号空間 × 電荷」に入る。
4. 論理忠実度：8 つのホロノミーのセクターごとに「$B$ に入っているか」と「$Q$ の値」を読み、初期状態との重なりを**厳密な数**として計算する（標本ではない）。

## 5. 計算の手間

* $B$ の方程式と $Q$ の係数は、どちらも高々 $k\times k$ の 0/1 行列（$k=3L^2$）。64 ビットずつまとめて演算する。1 回の測定は $O(k^2)$ ビット演算で、$L=9$（$k=243$）でも行列は約 7 KB。
* 実測（現象論的雑音、$p=2\%$、復号を含む 1 ショット、1 プロセス）：

| $L$ | 量子ビット数 | twisted frame（本番のエンジン） | 同じ処理を Pauli proxy 法で | 状態ベクトル |
|---|---|---|---|---|
| 3 | 81 | 0.33 ms | 4.1 ms | $2^{27}$ 成分、GPU で 1 ショット 0.1〜1 秒 |
| 5 | 225 | 0.89 ms | 18 ms | 不可能（$2^{75}$） |
| 7 | 441 | 2.2 ms | 79 ms | 不可能 |
| 9 | 729 | 6.3 ms | 236 ms | 不可能 |

Pauli proxy 法の列は、同じ処理を 1 ショットずつ Python で回す実装の値である。同じ駆動部どうしで比べると twisted frame の約 3.5〜6.8 倍遅く、本番のエンジン（まとめて処理する）とは 37 倍の差がある（後者には実装の工夫の差も入っている）。

## 7. なぜ研究 1 でこれが使えるのか、そして使うべきか

### 7.1 使える理由（前提が満たされている）

twisted frame が厳密であるための前提と、研究 1 での状況：

| 前提 | 研究 1 |
|---|---|
| 初期状態が誤りの無い符号状態（$\phi_0$ の恒等式が使える） | 記憶実験は誤りの無い符号状態から始める |
| 雑音が Pauli 誤り（確率的な X・Y・Z） | 現象論的雑音（脱分極＋測定結果の反転）も、符号容量型も、回路レベルの Pauli 雑音も満たす |
| 操作が Pauli、CZ、Z 型検査、dressed 検査（Z 付きを含む）だけ | 記憶実験の操作はこれだけ。回路レベルでも、CNOT と CCZ の回路を通った Pauli 故障は「Pauli × CZ」になり、測定は「dressed 検査（＋Z）の射影＋その後の Pauli・CZ 誤り」になる（故障表で確認） |
| 状態が平坦な配位の上にある | X 誤りは $x$ に分けて記録するので、$B$ はいつも平坦な配位の中にある |
| D4 符号の構造（検査の CZ が 2 次式、検査の動きが平坦な配位の中に収まる） | D4 符号そのもの |

### 7.2 使うべき理由

1. **近似がない**。旧研究の近似では表せなかった非可換性（再ランダム化）と CZ 型の残り物が、そのまま入る。研究 1 の結論（交点が約 2%、旧研究の 2.4% との差）は、この効果を正しく入れたことに依存している。
2. **速い**。$L=9$ で 1 ショット約 6 ms で、$10^5$ ショット × 10 点 × 4 サイズ × 対照実験 3 種の本番が、Colab の 1 台で約 10〜15 時間に収まる。$L=11$ も視野に入る。状態ベクトルは $L=3$ が限界で、汎用の Pauli proxy 法は同じ処理で数倍〜数十倍遅い。
3. **結果が確率と忠実度の「正確な数」で出る**。各測定がランダムだったかどうか、最終状態の論理忠実度（0 と 1 の間の値も含む）がそのまま分かるので、「フラックスの無い層でのランダムな結果の割合」のような診断量も正確に取れる。
4. **独立な検算ができる**。研究 2・3 で使う Pauli proxy 法とは実装を共有しない別の方法なので、両者の一致が双方の正しさの強い証拠になる。

### 7.3 使えない（使うべきでない）場面

* 論理的な非 Clifford ゲート（code switching の $U$ など）を含むプロトコル：研究 2・3 は Pauli proxy 法を使う。
* 境界のあるパッチ：原理は同じだが、今の実装はトーラス専用。
* Pauli でない雑音（コヒーレントな誤り）や、CCZ を T ゲートなどに分解したときの内部の故障。
* D4 以外の符号（平坦な配位と 3 次の符号という構造に依存する）。より高い階層（研究 5 の $N\ge4$）では検査に CCZ が入り、この形は保たれない。

## 8. Takada らの方法との関係

Takada–Bartlett–Williamson の Clifford-stabilizer simulation は、「非可換でも、安定化される部分空間の上では可換な」安定化子の群を追いかける一般的な方法である。twisted frame はその**特別な場合**にあたる。

* D4 符号の 2 つの検査の交換子は Z 型検査（プラケット）の積なので、各測定は「実効的に可換か反可換」で、結果は確定か 1/2 になる（Takada の VI.A 節の条件）。
* 場合 (ii) の更新は、Takada の「反可換な測定の更新則」（IV・VI.B 節）を、状態の側で書いたもの。
* $f$ の中の $q(b+s+x)+q(b+s)$ は、Takada の「Pauli dressing」にあたる。

違いは状態の持ち方である。Takada の方法は、非 Pauli の因子を Pauli に置き換えた代理の状態（Pauli 安定化子の表）を持ち、条件を満たせばどの符号にも使える。twisted frame は D4 符号の構造を使って本物の状態の台と符号を直接持つので、符号専用だが、振幅の情報がそのまま得られ、速い。

なお「twisted frame」という名前は先行研究の用語ではなく、この研究で付けたものである。論文では、最初に出るところで "we call this representation the *twisted frame*" のように、こちらで付けた名前だと分かる書き方にするのがよい。
