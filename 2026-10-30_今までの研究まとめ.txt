今までにやった3研究

1. D4符号の閾値評価
Kobayashiさんたちの論文『Clifford Hierarchy Stabilizer Codes』にあるD4符号の閾値を、Stimで再現可能な代替モデルの「メインコード」と、その代替モデルが物理エラー率-論理エラー率のプロットを正しく描けていることを示す「正当化コード」の組み合わせで求めた。

2. Code Switchingの論理誤り率、閾値
（可換な普通の）表面符号の初期状態からスタートし、物理エラー率pでD4符号に突入→（理想的な無エラーの）論理Tゲートをかける→表面符号に戻る、という一連の流れを経て、「正しく論理Tゲートがかかった状態」に復号できなかった割合（論理エラー率）を調べる。符号の閾値研究と同様、今回も閾値を求めた。

3. Code Switchingのコスト評価
物理エラー率pと目標論理エラー率p_Lを固定した時、各p, p_Lに対し魔法状態蒸留とCode Switching（D4符号）はどちらが優位であるか、なるべく公平な条件で比較する。

4. Code Switchingのコスト評価その2
研究3で複数の物理エラー率p及び複数の目標論理エラー率で試したところ、Code Switchingが魔法状態蒸留よりも優位だった条件は一つもなかった
- 今回のシミュレーションは「Switch in→論理Tを1つだけ構成→Switch out」の流れを再現しているが、Switch inした後で複数の非Cliffordゲートを実装する回路なら優位性があるかも？というのを探るのが研究4
- でも「Switch inの後にTゲートを2回かける」だと実用的な意味がないので、実用性のある設定の中でCode Switchingに有用性がある場面があるかを探る（Tゲートの後にCCZとかだと意味あるかな？）
- 十分な理論的考察の上で、それを踏まえてシミュレーション、の予定
- 注意事項：無理やり「Code Switchingの方が優位」という"都合の良い"結果を得ようとしない。学術的に誠実な研究をする。
