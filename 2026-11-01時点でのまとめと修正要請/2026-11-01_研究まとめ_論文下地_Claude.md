## 要旨

Kobayashi、Zhu、Hsin が提案した 2 次元の $\mathbb{D}_4$ Clifford 階層安定化子符号（twisted $\mathbb{Z}_2^3$ ゲージ理論）[1] は、transversal な論理 $T$・$CS$ ゲートを持ち、folded surface code との code switching によって $O(d)$ ラウンドで論理 $T$ 魔法状態を準備できる。一方で、この符号の $X$ 型安定化子は CZ で「dressed」された非 Pauli の Clifford 演算子であり、その測定回路は CCZ を含む。さらに、$X$ 誤りがフラックスを作ると、色の異なる dressed 安定化子どうしが可換でなくなり、測定結果は測定の順序と時刻に依存する確率的なものになる。このため、通常の安定化子シミュレータでは雑音下の性能を評価できず、可換な Pauli 検査と独立な $Z$ 雑音で置き換える近似（以前の研究 [19]）ではこの効果を表せない。

本研究では、(i) Pauli 雑音の下で dressed 測定の列をたどっても状態が「平坦ゲージ配位のアフィン部分空間上の、$\mathrm{GF}(2)$ の二次位相を持つ一様重ね合わせ」にとどまることを使った厳密かつ多項式時間の標本化器（twisted-frame 表現）を構成し、just-in-time（JIT）フラックス補正と組み合わせて $X$ 安定化子側（電荷側）の記憶実験の有限サイズ交点を 3 つの雑音モデルで求めた（研究 1）。(ii) Takada、Bartlett、Williamson の Clifford-stabilizer simulation（Pauli proxy 法）[2] を、folded surface code → $\mathbb{D}_4$ 符号 → 論理 $T^\dagger$ → folded surface code という code switching 全体に適用し、現象論的雑音下で「目標の魔法状態が正しく得られなかった割合」を符号距離ごとに求めた（研究 2）。(iii) 同じ Pauli proxy 法を回路レベル雑音の code switching 回路全体に適用して出力誤り $\varepsilon_K(d,p)$ を求め、15-to-1 魔法状態蒸留（Litinski の構成 [5,6]）と、論理 $T$ 状態 1 個あたりの時空間体積を比較した（研究 3）。

研究 1 では、$L=3$ での状態ベクトルとの軌道ごとの一致（測定確率の差 $\le 6\times10^{-8}$）と独立標本の失敗率の一致を確認したうえで、各点 $10^4$ ショット、$L=3,5,7,9$ の本番計算で、電荷側の交点として符号容量型で 9.2〜10.2%、現象論的雑音で 2.25%→2.09%→2.00%、回路レベル雑音で 0.22%→0.19% を得た［確定（有限サイズ交点）］。現象論的・回路レベルでは交点が $L$ とともに低い $p$ へ移動しており、漸近閾値は確定していない。研究 2 では、総当たり計算・独立な厳密エンジン・本番経路の再生の 3 種の検証で不一致 0 を確認したうえで、理想化した切り替え境界（ideal）の `in_T_out` で交点 2.97%（$d=3$–5）、2.41%（$d=5$–7）を得た［確定（ideal 境界）］。研究 3 では、回路と復号器が 1 個の故障を必ずしも訂正しないこと（$d=3$ で一次の係数 $c_1=4.2$〜15.7）を明らかにし、$U$ 直前の $Z$ 検査ラウンドを 2 回にした現在の回路では、アイドル雑音なしの $\varepsilon_K$ が $d=3$ から $d=5$ で 1 桁以上下がる（$p=10^{-4}$ で $4.6\times10^{-4}\to2.0\times10^{-5}$）ことを確かめた。一方、資源比較の結論のうち「アイドル雑音なし・$p=10^{-4}$・要求誤り $10^{-4}$ で Kobayashi 方式が 0.54 倍の体積」という値は、当てはめたモデルを適用範囲外の $d=3$ に使った結果であり、同じ点の直接シミュレーション値（$4.6\times10^{-4}$）と矛盾するため撤回を要する［修正待ち］。シミュレーションした $d\le9$ のデータから直接言える範囲では、評価したすべての $(p,\varepsilon_{\rm target})$ で 15-to-1 蒸留の方が小さい体積で要求を満たす。

## 1. 序論

### 1.1 背景：非 Clifford ゲートの費用

汎用な耐故障量子計算には Clifford 群の外の論理ゲートが必要であり、transversal ゲートだけでは汎用な論理ゲート集合を作れない（Eastin–Knill の定理 [9]）。さらに、$n$ 次元の位相的 Pauli 安定化子符号の定数深さの論理ゲートは Clifford 階層の第 $n$ 層に限られる（Bravyi–König の定理 [8]）。2 次元の表面符号で論理 $T$ ゲートを実現する標準的な方法は、雑音のある魔法状態を蒸留して高忠実度の論理魔法状態を作り、ゲートテレポーテーションで消費する方法である [7,21]。15-to-1 蒸留の格子手術による配置と費用は Litinski によって詳しく評価されており [5,6]、近年は magic state cultivation [14] のように費用を大きく下げる提案も続いている。

### 1.2 Clifford 階層安定化子符号と $\mathbb{D}_4$ 符号

Kobayashi、Zhu、Hsin [1] は、安定化子群に非 Pauli の Clifford 階層演算子を含む「Clifford 階層安定化子符号」を導入し、Bravyi–König の制約の外にある transversal 論理ゲートを構成した。2 次元では、twisted $\mathbb{Z}_2^3$ ゲージ理論（Dijkgraaf–Witten 型のゲージ理論 [24]。非可換な $\mathbb{D}_4$ トポロジカル秩序と等価で、22 種のエニオンを持つ）に対応する Clifford 安定化子符号が得られ、cup 積で表される自己同型により transversal な論理 $T$・$CS$ ゲートを持つ。$\mathbb{D}_4$ トポロジカル秩序はイオントラップ装置で実現されている [18]。

この符号の $Z$ 型安定化子は通常の Pauli プラケット演算子であるが、$X$ 型安定化子は頂点の Pauli $X$ の積に CZ を掛けた「dressed」な演算子である。[1] は、folded surface code から $\mathbb{D}_4$ 符号への code switching（gauging 測定）と JIT 復号器 [3] を組み合わせ、$O(d)$ ラウンドで論理 $T$ 魔法状態を耐故障に準備する手順を示した。関連する非可換符号は、2 次元での汎用耐故障計算の提案 [3,4] の中心にもある。

### 1.3 シミュレーション上の二つの困難

$\mathbb{D}_4$ 符号の雑音下の性能評価には二つの困難がある。

1. **測定回路が非 Clifford である。** dressed 安定化子を補助量子ビットで測ると、CZ 因子が補助量子ビットに制御されて CCZ になる。$U=WV$（論理 $T^\dagger$）も CS、CS$^\dagger$、$T^\dagger$ を含む。したがって Gottesman–Knill の定理 [12,13] に基づく Stim [10] のような安定化子シミュレータでは直接扱えず、状態ベクトルは $L=3$ の 81 データ量子ビットでも扱えない。
2. **dressed 安定化子はフラックスのない部分空間でしか可換でない。** $X$ 誤りがプラケットの $Z$ 検査を破る（フラックスを作る）と、色の異なる dressed 安定化子が反可換になりうる。このとき、ある dressed 安定化子を測ると別の dressed 安定化子の結果がランダムになり、$A\to B\to A$ と測ると最後の $A$ は最初の $A$ と確率 1/2 でしか一致しない。シンドロームは誤り配位の決定的な関数ではなくなる。

以前の研究 [19] は、dressed な検査を可換な bare Pauli-$X$ 検査に置き換え、dressing の効果を dressed 量子ビット対への独立な $Z$ 雑音（率 $r=\kappa c p$）として注入する「Clifford サロゲート」で閾値を見積もった（符号容量型 2.6%、現象論的 2.4%、回路レベル 0.62%）。この方法は 2 番目の困難（非可換性による状態の再ランダム化）を表せず、$\kappa$ の較正も「1 つの検査を 2 回測る」統計に基づくため、その不足を検出できなかった。

### 1.4 本研究の目的と貢献

本研究は、上の困難を厳密なシミュレーションで乗り越え、$\mathbb{D}_4$ 符号と code switching の性能を三つの段階で評価する。

* **研究 1（$\mathbb{D}_4$ 符号の閾値）**：トーラス上の $\mathbb{D}_4$ 符号の記憶実験について、dressed 測定の非可換性を厳密に扱う twisted-frame 標本化器を構成し、JIT フラックス補正の下で $X$ 安定化子側（電荷側）の有限サイズ交点を 3 つの雑音モデルで求める。dressing を外した対照実験で非可換性の効果を切り分ける。
* **研究 2（code switching の論理誤り率）**：表面符号の初期状態から雑音下で $\mathbb{D}_4$ 符号に切り替え、理想的な論理 $T^\dagger$ をかけ、表面符号に戻す一連の手順を、Takada らの Clifford-stabilizer simulation [2] で厳密に標本化し、目標状態が得られなかった割合と、その交点を求める。
* **研究 3（code switching のコスト評価）**：回路レベル雑音で code switching 全体を同じ方法でシミュレーションし、物理誤り率 $p$ と要求出力誤り $\varepsilon_{\rm target}$ を与えたとき、15-to-1 蒸留と code switching のどちらが小さい時空間体積で論理 $T$ 状態を作れるかを、なるべく公平な条件で比べる。

方法の面での共通点は、**非 Clifford 回路を、標本ごとに測定統計が等しい Clifford 回路（または等価な有限の代数的表現）に写して厳密に標本化する**ことである。研究 2・3 は Takada らの方法 [2] をそのまま採用し、研究 1 は同じ構造を $\mathbb{D}_4$ 符号に特化した独自の表現（アフィン部分空間と二次位相）で実装した。研究 2 の検証では、この二つの独立な厳密エンジンが同じ入力に対して全ての測定結果で一致することも確認した（第 5.3 節）。

## 2. 理論的背景

### 2.1 Clifford 階層、Clifford 安定化子と実効的な可換性

Clifford 階層は $\mathcal{C}^{(1)}$ を Pauli 群とし、$\mathcal{C}^{(k)}=\{U: U\mathcal{C}^{(1)}U^\dagger\subset\mathcal{C}^{(k-1)}\}$ で帰納的に定義される。CZ、S は第 2 層（Clifford）、CCZ、CS、$T$ は第 3 層である。

Takada ら [2] は、Pauli 安定化子と非 Pauli の Clifford 演算子（Clifford 安定化子）で生成される有限群で、自明でない共通 $+1$ 固有空間を持つものを **Clifford-stabilizer group** と呼んだ。Clifford-stabilizer group は一般に非可換であるが、その要素は安定化子部分空間の上では可換である。すなわち、群交換子 $[A,B]=ABA^\dagger B^\dagger$ が状態 $|\psi\rangle$ に $+1$（$-1$）で作用するとき、$A$ と $B$ は $|\psi\rangle$ 上で**実効的に可換（反可換）**であるという。対角な第 3 層の論理ゲートに対応する魔法状態では、Clifford 安定化子どうしの群交換子は $Z$ 型の Pauli 安定化子になる。

$\mathbb{D}_4$ 符号はまさにこの構造を持つ。dressed $X$ 安定化子どうしの群交換子は面の $Z$ 演算子の積であり、フラックスのない（全ての面 $Z$ 検査が $+1$ の）部分空間では恒等、フラックスのある部分空間では $-1$ になりうる。

### 2.2 三角形分割トーラス上の $\mathbb{D}_4$ 符号（研究 1 の幾何）

研究 1 では、$L\times L$ の正方格子の各正方形を対角線で二つの三角形に分けたトーラスを使う。頂点 $L^2$ 個、辺 $3L^2$ 本、三角形 $2L^2$ 個である。各辺に赤・緑・青（$r,g,b$）の 3 量子ビットを置くので、データ量子ビットは $n=9L^2$ 個（$L=3$ で 81、$L=9$ で 729）である。

* **$Z$ 型安定化子（面）**：各三角形 $f$ と各色 $c$ に $Z^c_f=\prod_{e\in\partial f}Z^c_e$。計 $6L^2$ 個。
* **$X$ 型安定化子（頂点、dressed）**：各頂点 $v$ と各色 $c$ に
$$
S^c_{X;v}=\prod_{e\ni v}X^c_e\;\prod_{(e,e')}\mathrm{CZ}^{c',c''}_{e,e'},
$$
  CZ の対は cup 積から決まり、$c$ 以外の 2 色 $(c',c'')$ の量子ビットに作用する。三角形 $(v_0,v_1,v_2)$ について、赤のチェックは $v_0$ に、緑は $v_1$ に、青は $v_2$ に CZ 対を持ち、特に緑のチェックの位相は $a_r(e_{01})a_b(e_{12})$ である（KZH の補足資料のカップ積の順序）。各 dressed チェックは $X$ 台 6 個と CZ 対 2 個からなる。

以前の研究のコードでは緑のチェックの CZ 対の辺と色の対応が逆で、フラックスのない部分空間でも非可換な対が残っていた（$L=3$ で 90 対）。v5 以降はこれを修正し、v7 では演算子として非可換な対は $L=3$ で 27 対あるが、フラックスのない部分空間で非可換な対は 0 であることを確認している（第 4.3 節）。

### 2.3 dressed 安定化子の非可換性

dressed 安定化子を $S_A=X^{s_A}(-1)^{q_A(a)}$ と書く（$a$ は $Z$ 基底の配位、$q_A$ は CZ 対から来る二次形式）。交換関係は
$$
S_AS_B=S_BS_A(-1)^{\Delta_{AB}(a)},\qquad
\Delta_{AB}(a)=q_A(a+s_B)+q_A(a)+q_B(a+s_A)+q_B(a)\pmod 2
$$
である。$\Delta_{AB}$ は $a$ の一次関数であり、面 $Z$ 検査の値（フラックス）の線形結合で表される。交換子が $-1$ になるフラックス配位では、$A$ を測った後に $B$ を測ると、$A$ の固有状態は $B$ の測定で壊され、再び $A$ を測ると結果は確率 1/2 になる。この再ランダム化はフラックスが残っている間続き、独立な測定ビット誤りを加えることとは異なる。測定後の状態そのものが変わるからである。

さらに、隣接するフラックスを Pauli $X$ の補正で閉じても、誤りと補正が作る閉路が dressed 安定化子の積ではなく bare な $X$ 星の積になる場合、状態には CZ 型の残差が残る。この残差も dressed 測定の結果をランダムにしうる（第 4.6 節で、符号容量型でもランダムな結果が観測されることを述べる）。

### 2.4 平面パッチ、folded surface code と code switching（研究 2・3）

[1] の Fig. 4 に従い、正方形を対角線で分けた三角形状の平面パッチを使う。境界は $\mathcal{L}_r$（$a_r=0$）、$\mathcal{L}_b$（$a_b=0$）、$\mathcal{L}_{rb}$（$a_r+a_b=0$, $a_g=0$）の 3 種で、赤・青の 2 色の層は folded surface code（FSC）を作る。論理量子ビットは 1 個である。

code switching による論理 $T$ 魔法状態の準備（[1] の手順）は次のとおりである。

1. FSC（赤・青）を論理 $|+\rangle$ に準備し、緑の量子ビットを $|0\rangle$ に初期化する。
2. $\mathbb{D}_4$ 符号の全ての安定化子（緑の $S^g_{X;v}$ は最初はランダムな固有値）を $O(d)$ ラウンド測定する。その間、面 $Z$ 検査で見えるフラックスを JIT 復号器で実時間にペアにし、最後に残った可換な電荷（$Z$ 誤り）を整理する（gauging）。
3. transversal な $U=WV$ を作用させる。$V=\prod_e\mathrm{CNOT}(r\to g)\mathrm{CNOT}(b\to g)$、$W$ は CS、CS$^\dagger$、境界の $T^\dagger$ の積で、$U$ は論理 $T^\dagger$ になる。
4. 緑の量子ビットを $Z$ 基底で測り、結果に応じて $S^g_X$（の CZ 部分）を作用させて FSC に戻し、$O(d)$ ラウンドの誤り訂正を行う。

出力は $T^\dagger|+\rangle$ である。$XT^\dagger|+\rangle=e^{-i\pi/4}T|+\rangle$ なので、Pauli フレームの更新だけで $T|+\rangle$ と同等に使える（研究 3 の比較では両方式とも出力は $T^\dagger|+\rangle$）。

### 2.5 15-to-1 魔法状態蒸留（研究 3 の比較対象）

15-to-1 蒸留は、15 個の雑音のある $T$ 状態から誤り検出によって 1 個の高忠実度の状態を作る [7]。入力の誤りが独立で確率 $\epsilon$ なら出力誤りの主要項は $35\epsilon^3$ である。Litinski [5] は表面符号の格子手術による配置（11 tile × 11τ の 15-to-1、176 tile × 15τ の 225-to-1）を示し、[6] は $X$・$Z$ の距離と測定の距離を別々に選んだ最適化された蒸留器 $(15\text{-to-}1)_{d_X,d_Z,d_m}$ と 2 段の構成、およびそれらの誤り予算モデルを公開コードとともに与えた。

## 3. 手法

### 3.1 Takada らの Clifford-stabilizer simulation（研究 2・3 の基盤）

Takada、Bartlett、Williamson [2] は、Clifford 階層の第 3 層の非 Clifford ゲートに使う論理魔法状態の準備プロトコルを、回路レベルの Pauli 雑音の下で**厳密かつ多項式時間で**シミュレーションする方法（Clifford-stabilizer simulation）を与えた。要点は次のとおりである（節番号・式番号は [2] のもの）。

1. **Clifford-stabilizer group による状態の記述**（Sec. III）。多くの論理魔法状態（表面符号の $|\bar T\rangle$、$[\![8,3,2]\!]$ 符号の $|\overline{CCZ}\rangle$ など）は、Pauli 安定化子と非 Pauli の Clifford 安定化子の共通 $+1$ 固有状態として一意に定まる。
2. **Pauli dressing と実効的な可換性**（Sec. IV、VI A）。Pauli 誤り $E_P$ が Clifford 因子 $C$ を共役すると $E_PCE_P^\dagger=D_C(E_P)C$ となり、$D_C(E_P)=[E_P,C]$ は（位相付きの）Pauli 演算子になる。CZ や S に対する $X$／$Y$ 誤りのドレッシングは単一量子ビットの $Z$ である。全てのドレッシングが元の生成元と可換または反可換であれば、測定は元の生成元と実効的に可換または反可換になり、測定結果は決定的か一様ランダムのどちらかになる。
3. **更新則と十分条件**（Sec. VI）。primary-support exactness（Definition 1）と admissible な生成元の集合（Definition 2）の下で、誤りと Pauli／Clifford 安定化子の測定の任意の列に対する Clifford-stabilizer group の更新則（Theorem）が成り立つ。論理誤りは、雑音なしの仮想的な誤り訂正の後に、目標状態の論理 Clifford 安定化子を仮想的に測ることで評価する（Sec. VI D）。
4. **measurement-conjugated picture と Pauli proxy**（Sec. VII A, B）。誤り $E$ を状態に作用させる代わりに、測定する演算子を $\tilde M=E^\dagger ME$ に置き換え、状態は理想のまま保つ（frame state）。さらに、元の生成元の Clifford 因子を、全ての可能なドレッシングとの可換・反可換の関係を保つ Pauli 演算子（**Pauli proxy**）で置き換える。これは演算子の等式でも近似でもなく、交換関係を再現するための還元規則であり、その結果、Clifford-stabilizer group の更新を Pauli 安定化子群の更新として Clifford シミュレータで実行できる。
5. **アルゴリズム**（Sec. VII C, D）。演算子レベル（Algorithm 1）と回路レベル（Algorithm 2）の実装がある。回路レベルでは、標本化した Pauli 誤りの $X$ 成分を Clifford ゲートに沿って前向きに伝播させ、真の回路から対角な第 3 層ゲート $D$ を取り除き、$X$ 成分が $D$ に当たる位置にドレッシング（$D$ と $X$ 成分の交換で生じる Clifford 演算子）を Clifford ゲートとして挿入する。こうして得た 1 本の Clifford 回路は、雑音を標本化した非 Clifford 回路と同じ測定統計を厳密に再現する。
6. **適用範囲**（Sec. VIII）。transversal な非 Clifford ゲート、分岐反転を伴う途中測定と補正（Algorithm 3）、ancilla のリセットなども扱える。[2] は応用として fault distance 7 までの magic state cultivation の厳密シミュレーションを示し、twisted quantum double の魔法状態準備プロトコルへの応用を今後の方向として挙げている。

関連する先行手法として、Surti、Daguerre、Kim [15] は第 3 層の論理魔法状態準備を多項式時間で扱うが、目標状態を安定化子ランク分解で表すためそのランクに費用が依存する。Magdalena de la Fuente らの方法 [4] は効率的な標本化を与えるが論理誤り率の上界にとどまる。[2] はいずれの制約も持たない。

本研究との関係は次のとおりである。

* **研究 2** は [2] の measurement-conjugated picture、Pauli dressing、Pauli proxy（Sec. VII A–C、Algorithm 1）、transversal 非 Clifford ゲートと分岐反転補正（Sec. VII D、VIII、Algorithm 3）、仮想的な Clifford 安定化子測定による論理誤りの評価（Sec. VI D）を、現象論的雑音の code switching に適用した。Pauli proxy の Clifford 回路は `stim.TableauSimulator` で実行する（第 3.3 節）。
* **研究 3** は [2] の回路レベルの Algorithm 2 を、CCZ ガジェット・CS・$T^\dagger$ を含む回路全体に適用した（第 3.4 節）。[2] の著者のコードは使わず、本研究で実装した。
* **研究 1** は [2] の実装を使っていない。$\mathbb{D}_4$ 符号に特化した独自の厳密表現（第 3.2 節）を用いた。ただし、扱っている構造（Clifford 安定化子の群交換子が $Z$ 型の Pauli 安定化子になり、Pauli 誤りの下で測定は実効的に可換または反可換、結果は決定的か一様ランダム）は [2] が一般的に定式化したものと同じである。したがって研究 1 の記憶実験は、原理的には [2] の方法でも厳密に標本化できるはずであり、その再実装は二つの独立な実装の相互検証として有用である（第 9 節）。

### 3.2 研究 1 の twisted-frame 表現

研究 1 の標本化器は、1 ショットの状態を次の形で厳密に保持する。
$$
\psi(a)\;\propto\;(-1)^{\phi_0(b)+Q(b)}\,\mathbf{1}[\,b\in B\,],\qquad a=b+x .
$$
ここで $a$ は $Z$ 基底の配位、$x\in\mathrm{GF}(2)^n$ は物理的な $X$ フレーム（Pauli $X$ 誤りと補正の記録）、$B$ は平坦なゲージ配位の空間 $C_0$ の中のアフィン部分空間、$Q$ は $B$ 上の $\mathrm{GF}(2)$ 二次形式、$\phi_0$ は初期の twisted 符号状態の位相（3 次）である。$\phi_0$ は dressed 安定化子の恒等式 $\phi_0(b+s)+\phi_0(b)=q(b)$ により、標本化の途中では一度も必要にならない。座標は $b=Mt$（$t\in\mathrm{GF}(2)^k$、$k=3(L^2-1)+(\text{論理色の数})$）で、各色の頂点の星（頂点 0 を除く）と、論理セクター用の $x$ 方向のホロノミーを基底とする。

dressed チェック $S=X^s(-1)^{q(a)}$ の理想射影測定の比 $(S\psi)(b)/\psi(b)$ は $b$ のアフィン関数 $f(b)$ になり、更新は次の 2 通りに限られる（`tf_measure`）。

* (i) $s$ が $B$ の方向空間に含まれる：$f$ が $B$ 上で定数なら結果は決定的。定数でなければ結果は確率 1/2 で、$B$ を対応する超平面に制限する。
* (ii) $s$ が $B$ の方向空間に含まれない：結果は確率 1/2。$B$ を $B\cup(B+s)$ に広げ、$Q$ に二次の項を加える。これが、先の測定で得た情報が別の色の測定で失われる過程（$A\to B\to A$ の再ランダム化）を厳密に表す。

Pauli $Z$ 誤りは $Q$ の一次項、Pauli $X$ 誤りは $x$ の更新、データ上の CZ（回路レベル雑音での CCZ ガジェットの故障の伝播）は $Q$ の二次項の更新（`tf_apply_cz`）になる。全ての操作は $\mathrm{GF}(2)$ の行列演算であり、費用は系の大きさの多項式である。ビット列は 64 ビット語に詰め、Numba [23] で実行する。

この表現の中では、論理状態は $x$ 方向の 3 色のホロノミーを重ね合わせた 8 セクター（`logical_colors="rgb"`）または 1 色の 2 セクター（`"r"`）で、終了時のセクター表から論理忠実度 $F$ を計算し、確率 $1-F$ で失敗を標本化する。

### 3.3 研究 2 の実装：誤りフレームと Pauli proxy

研究 2（`chsc_switch_v3.py`）は、[2] の measurement-conjugated picture に従い、物理状態を $E|\text{frame}\rangle$ と書く。誤りと補正の累積 $E$ を
$$
E=X^{x}\,\mathrm{diag}\!\left(\omega^{\gamma(a)}\right),\qquad
\gamma(a)=\sum_i l_ia_i+4\sum_{i<j}Q_{ij}a_ia_j\pmod 8,\qquad \omega=e^{i\pi/4}
$$
の形（Pauli $X$ フレームと対角 Clifford の積）で保持する（`ErrorFrame`）。$U$ を作用させる前の $E$ は Pauli であり、$X$ 誤りが transversal な $W$（CS、$T^\dagger$）を通過したとき、および緑の補正 $S^g_X$ の CZ 部分を通したときに、S 型・CZ 型の対角 Clifford 成分が現れる。

dressed 生成元 $M=X^s\Delta$（$\Delta$ は CZ dressing）を測るときは、
$$
E^\dagger ME = X^s\Delta\,\mathrm{diag}\!\left(\omega^{[\delta(a+x)-\delta(a)]+[\gamma(a)-\gamma(a+s)]}\right)
$$
の第 2 因子が Pauli dressing（位相付きの $Z$ 列）になり、$\Delta$ をその Pauli proxy（恒等、すなわち dressed 生成元の proxy は bare な $X$ 星）で置き換えると Pauli 演算子が得られる。これを Stim の MPP で測る（`ProxyBackend.measure_gens`）。本番経路（`lockstep=False`）は MPP を区間ごとにまとめて実行し、符号ビットを後で反映する。

この還元がこのプロトコルで厳密であることの十分条件として、研究 2 は次の 3 条件を各 $d$ で数値的に確認する（`check_intertwiner_conditions`）。$C=\mathrm{diag}((-1)^{\phi_0})$ とする。

* (C1) 全ての dressed 生成元 $G=X^{s_G}\mathrm{CZ}^{\rm pairs}$ と全ての平坦配位 $a$ について $\phi_0(a+s_G)=\phi_0(a)+q_G(a)$。すなわち平坦部分空間上で $CX^{s_G}C^\dagger=G$ で、$G$ の proxy は $X^{s_G}$。
* (C2) $a_g=0$ の全ての平坦配位で $\phi_0(b)=0$。すなわち $C$ は FSC の状態に自明に作用する。
* (C3) 平坦部分空間上で $UC=CVT_h$（$T_h=\mathrm{diag}(\omega^{\kappa h})$、$h$ は論理 $\bar Z$ のパリティ）。すなわち $U$ の proxy は $V$ で、論理 $T^\dagger$ は $T_h$ として帳簿に残す（[1] の Theorem 2 の点ごとの形）。

$U$ の作用（`apply_U`）は、frame 側では CNOT 網 $V$ を Stim で実行し、$E$ を $UEU^\dagger$ に共役する（`conj_U`）。switch-out の緑の $Z$ 測定（`measure_green_switch_out`）は、frame を $Z^g=+1$ に射影し、真の分岐反転演算子 $S^g_X(\lambda)$ を $E$ に右から掛ける（[2] の Algorithm 3）。最後の論理評価（`evaluate_class`）は、目標状態の Clifford 安定化子の Pauli proxy（誤りフレームで共役し、$T^\dagger$ の場合は $T_h$ の効果を含める）の期待値を Stim で読み、出力状態を $\{I,X,Y,Z,S,\text{collapsed}\}$ の類（`in_only` ではさらに flux_D4）に分類する。$P_L$ は「最終状態が目標状態そのものでない」割合 $1-P(I)$ である。

### 3.4 研究 3 の実装：回路レベルの Pauli proxy（Algorithm 2）

研究 3（`tools/noisy_d4_lib.py` の `FastShot`、`D4Experiment`）は、[2] の Algorithm 2 をそのまま実装した。1 ショットごとに、

1. 雑音モデルから Pauli 誤りを標本化する。
2. 真の回路から対角な第 3 層ゲート $D$（CCZ、CS、CS$^\dagger$、$T^\dagger$）を取り除き、Clifford 部分を Stim の `TableauSimulator` で実行する。
3. 標本化した誤りと、実際に適用した $X$ 補正の $X$ 成分 $e$ を、Clifford ゲート（CNOT）に沿って前向きに追跡する（$Z$ 成分は対角ゲートと可換なので追跡不要）。
4. $D$ の位置で $e$ が $D$ の台に乗っていれば、$D$ の代わりにドレッシング $C_e=D^\dagger X^eDX^e$（S、Z、CZ の積で Clifford）を挿入する。$DX^e=X^eDC_e$ なので、「誤り $X^e$ が $D$ を通過した」効果を Clifford で正確に表す。

適用条件として、(a) X 型 Clifford 安定化子の $X$ 因子と CZ 因子の台が互いに素（transversal）、(b) CZ・S に対する $X$／$Y$ 誤りのドレッシングが単一量子ビット $Z$、(c) 測定する生成元どうしの群交換子がその時点の $Z$ 安定化子の張る空間に入る（実効的可換性）、(d) primary-support exactness（$X$ 台が線形独立）、(e) $U$ と switch-out の補正が CNOT と対角第 3 層ゲートのみ、(f) 出力の論理安定化子 $\bar H$ が Clifford で FSC の $X$ 検査と実効的に可換、を $L=2..7, 9$ で厳密な演算子比較により確認した（`takada_conditions`、検証 N1）。switch-in では、FSC $|+_L\rangle\otimes|0\rangle_g$ の生成元を $\mathbb{D}_4$ 側の CZ でドレスしたもの（$|0\rangle_g$ 上では自明）と CZ でドレスした論理 $\bar X$ を生成元に選ぶ（[2] Sec. VIII B の生成元の選び方。裸の FSC 生成元では (c) が成り立たない）。

研究 3 では、さらに次の工夫を加えている。S0（FSC の準備）は Clifford 回路なので、S1 の開始時に Stim の状態から $Z$ 検査の符号を読み、$X$ フレームを $\mathrm{GF}(2)$ の連立方程式で求める（[2] の Algorithm 3 は不要）。switch-out の測定結果に依存する CZ は、シミュレーション上は「遅延測定」形式の雑音なし仮想 CCZ 網で表し、読み出し後に (1) 仮想網の CZ を雑音なしで取り除き、(2) flux 復号器の $X$ 補正を適用し、(3) 物理的な補正 CZ を固定の層スケジュールで、各 CZ の後に 2 量子ビット脱分極を入れて適用する。出力の評価は [2] Sec. VI D に従い、雑音なしの FSC ラウンドで復号した後、理想出力の論理 Clifford 安定化子 $\bar H$ の proxy の期待値 $\langle\bar H\rangle\in\{1,0,-1\}$ を読み、不忠実度 $(1-\langle\bar H\rangle)/2\in\{0,1/2,1\}$ の平均を出力誤り $\varepsilon_K$ とする。

### 3.5 復号器

#### 3.5.1 JIT フラックス復号（研究 1、研究 2）

$\mathbb{D}_4$ 符号ではフラックスが dressed 測定を乱し続けるので、面 $Z$ 検査で見えるフラックスを実時間で補正する必要がある（[1,3]。JIT 復号の考え方は [16,17] に由来する）。研究 1 の `JITFluxDecoder` は色ごとに次を行う。

* 各ラウンド $t$ で、面の $Z$ 検査の結果から、それまでに適用した補正によるフラックスを差し引いた「補正済みシンドローム」を作り、前ラウンドとの差を検出事象として、時刻付きで未解決の集合に加える。
* 層 $0..t$ の時空グラフで MWPM（PyMatching [11]）を行う。空間辺の重み $w_s=\ln[(1-p_X)/p_X]$、時間辺 $w_t=\ln[(1-p_M)/p_M]$。層 $t$ の各ノードは重み $\texttt{offset}\cdot w_t$ で「未来境界」に接続する。時刻 $\tau$ の事象を保留するコストは $w_t(t-\tau+\texttt{offset})$ になる。
* 実事象どうしが組になったら、その面の間の最短の双対パスに $X$ 補正を同じラウンドの dressed $X$ チェックの前に作用させ、両方を未解決の集合から除く。未来境界と組になった事象は次のラウンドに持ち越す。真の誤り位置や将来の記録は使わない。

単一の $X$ 誤りが作る隣接した 2 事象は、組のコスト $w_s$ が待つコスト $2w_t$ より小さいので即座に補正される。孤立した事象（多くは面の測定誤り）は次のラウンドまで待ち、同じ場所に現れた相方と時間方向に組になる。`jit_boundary_offset=0`（新しいフラックスは必ず 1 ラウンド残る）では、試した範囲で誤り抑制が見られなかったと報告されている（実装と未解決事項_v7.md §5）［試行値］。

研究 2 の `JITDecoder` は同じ考え方を境界のある平面グラフに一般化したもので、空間境界とのマッチングもその場で補正する。実装上は、未来境界と組になった事象への経路の空間部分も補正し、保留する事象の位置をその経路の終点に移す点が研究 1 と異なる。保留コストの計算に使う時刻は、同じ検査で保留されていた事象の最も遅い時刻を引き継ぐ。通常の状況では未来境界への経路は同じ検査の時間辺だけを通るので、研究 1 とほぼ同じ動作になる。

研究 3 の flux 復号器（`FluxDecoder`）は、毎ラウンド、それまでの全ラウンドの時空間グラフ（未来側は開いた境界）を MWPM で復号し、確定した空間的な辺の $X$ 補正をその場で物理的に適用する（[1] の手順 2 の「flux を実時間でペアにする」の素朴な実装）。S0 の終わりと $U$ の前では全て確定させる。

#### 3.5.2 電荷（$X$ 型検査で見える $Z$ 誤り）の復号

* **研究 1**：bare な MPP 型の Stim 回路の detector error model を事前分布として、時空 MWPM で $x$ 方向の論理観測量のパリティを予測する。事前分布は物理の標本化には入らない。回路レベル雑音では、実回路（ネイティブ CCZ）の故障表から一次の近似で求めた「X チェック結果の反転率 $\approx6.4p$」「データの $Z$ 型誤り率 $\approx6.3p$／ラウンド」を事前分布に使う（`cl_decoder_prior="calibrated"`）。
* **研究 2**：赤・青の電荷は時空 MWPM で $Z$ 補正を決め、緑の電荷は最終シンドロームを推定して空間的にペアにする。ideal 境界では最後の完全ラウンドを使う。noisy 境界では最終層が未来境界で終われる復号器を使う。switch-out 後の表面符号は $d$ ラウンドの雑音のあるラウンドと 1 回の完全ラウンドで時空 MWPM。
* **研究 3**：プロトコル終了後に、Pauli proxy 回路の誤りモデル（Stim の DEM）上の MWPM で論理 $\bar H$ の反転を予測する。フラックスがあったラウンドでは CZ のドレッシングで dressed 検査の結果がランダムになるので、該当する辺の重みを下げる（消失として扱う）。switch-out をまたぐ検出器ではハイパーエッジが生じるので、2 つの基底で復号して重みの小さい方を採る。

現象論的雑音と時空 MWPM の考え方は [20] に従う。$\mathcal{D}_1(p)$ は単一量子ビット脱分極（非恒等 Pauli の確率 $p$、$X$ 成分・$Z$ 成分の周辺確率はそれぞれ $2p/3$）、$\mathcal{D}_2(p)$ は 2 量子ビット脱分極（15 通りが等確率）である。研究 1 の回路レベル雑音の「CCZ 後に 3 量子ビットそれぞれ $\mathcal{D}_1(p)$」は、3 量子ビット脱分極 $\mathcal{D}_3(p)$ ではない（少なくとも 1 量子ビットに誤りが出る確率は一次で $3p$）。研究 3 の CCZ は 3 量子ビット脱分極 $p$ である。したがって両研究の「回路レベル」の $p$ は同じ意味ではない。研究 1・3 とも、CCZ を 1 個の原始ゲートとして扱い、$T$ ゲート分解の内部の故障は扱わない。

### 3.7 統計処理

* **区間推定**：失敗率の区間は Agresti–Coull 区間 [25]（研究 1、2。信頼水準 95%）。研究 3 の $\varepsilon_K$ は 1/2 単位の不忠実度の平均で、標準誤差を示す。
* **交点の推定（研究 1、2）**：隣り合うサイズの曲線を log–log で線形補間して交点を求める（`estimate_crossings`）。区間は、各点の失敗率を Jeffreys 事後分布（Beta 分布）から再標本化し（研究 1 は 400 回、研究 2 は 300 回）、**交点が一つだけ出た標本**の分位点として求める。したがってこの区間は交点位置の標本変動を表すもので、有限サイズ効果・補間誤差・モデルの不確かさを含む「真の閾値の 95% 区間」ではない。交点が出なかった標本や複数出た標本の数も記録する。
* **研究 3 の当てはめ**：窓の外（bulk）の寄与を窓の雑音を 0 にした診断データに $\varepsilon_{\rm bulk}=\exp[a+cd+(b+ed)\log p]$、窓の項を本来のシミュレーションのデータに $W(p)=wp^\gamma$（$d$ によらないと仮定）として、$\varepsilon_K=\varepsilon_{\rm bulk}+W$ を最尤法（不忠実度の和を 1/2 単位の Poisson として扱い、失敗 0 の点も含める）で当てはめる。不確かさはパラメトリック・ブートストラップ（200 回）で評価する（第 6.6 節）。

## 4. 研究 1：$\mathbb{D}_4$ 符号の $X$ 安定化子の閾値

### 4.1 目的と設定

トーラス上の $\mathbb{D}_4$ 符号の記憶実験で、$X$ 安定化子側（電荷側、すなわち $Z$ 誤りに対する保護）の論理誤り率を、物理誤り率 $p$ と格子サイズ $L$ の関数として求め、隣り合う $L$ の曲線の交点から閾値を見積もる。目的は、Kobayashi らの $\mathbb{D}_4$ 符号の閾値を、dressed 測定の非可換性を厳密に含めた形で求め直すことである。

1 ショットのプロトコル（`sample_tf_memory`）は次のとおりである。

* **初期状態**：雑音のない $\mathbb{D}_4$ 符号状態（`logical_colors` の $x$ 方向ホロノミー・セクターの等重ね合わせ。既定は 3 色で 8 セクター）。
* **各ラウンド** $t=0,\dots,R-1$：(1) データ雑音（回路レベルではアイドル）、(2) 面の $Z$ 検査を全て測定（測定誤り、回路レベルでは補助量子ビット回路の故障を含む）、(3) JIT フラックス復号と物理的な $X$ 補正の即時適用、(4) dressed $X$ チェックを色の層の順（$r\to g\to b$）に 1 つずつ理想射影測定（測定誤り、回路レベルでは CCZ 回路の故障を含む）。
* **終了処理（理想化）**：(5) 完全な $Z$ 検査で残ったフラックスを MWPM で閉じる、(6) 残った $X$ フレームがホモロジー的に非自明ならフラックス側の論理失敗（flux 失敗）、自明なら dressed 安定化子のユニタリ作用で除く、(7) 完全な dressed $X$ チェックを 1 ラウンド行い、最終シンドロームとする。
* **電荷側の復号**：第 3.5.2 節の MWPM。予測した観測量と、標準補正後の状態のセクター位相から論理忠実度 $F$ を計算し、確率 $1-F$ で失敗とする。

失敗は次の 3 つの指標に分けて記録する（v7 で導入）。

* **charge**（主指標）：flux 側が成功したショットに条件付けた、電荷側の失敗率。$P_{\rm charge}=N_{\rm charge\ fail,\ flux\ ok}/(N-N_{\rm flux\ fail})$。
* **flux**：終了時に非自明な $X$ ループが残った割合（全ショットが分母）。
* **combined**：どちらかの失敗。$P_{\rm comb}=P_{\rm flux}+(1-P_{\rm flux})P_{\rm charge}$（条件付き確率の定義から成り立ち、独立性の仮定は不要）。

なお、flux 失敗の判定はシミュレーション内の真の誤りフレームを使う解析上の条件付けであり、実機でシンドロームだけから知って選別できるものではない。

### 4.6 考察

**(1) 中核の標本化器は検証された。** $L=3$ で、3 雑音モデルとも測定確率・最終忠実度が丸め誤差の範囲で一致し、独立標本の失敗率にも系統的な差は見られなかった。したがって、表 5 の数値は、「指定した雑音・初期状態・測定順序・JIT 復号・電荷復号器・理想化した終了処理からなる記憶実験」の論理誤り率の厳密な標本化に基づいている。以前の研究のサロゲートのように、非可換性の効果を調整パラメータで近似したものではない。

**(2) 現象論的雑音での交点は約 2.0% で、$L$ とともに下がっている。** 本番データの charge 交点は $L=3$–5、5–7、7–9 で 2.247%、2.088%、1.998% であり、下がり幅は 0.159、0.090 ポイントと小さくなっている。試行計算の $L=9$–11 は 1.89% であった［試行値］。したがって、現在のデータから言えるのは「最大サイズ対 $L=7$–9 の交点は約 2.0% で、有限サイズの下方ドリフトが残っている」ことであり、漸近閾値を 1.9% や 2.0% と確定することはできない。既存の原稿（v8、改変版 AQIS）にある「$p_{\rm th}\approx1.9\%$（$L\le11$）」は、本番データ（$L\le9$）と試行データ（$L=9$–11）を混ぜた値であり、確定値としては使えない（R1-1）。

**(3) 回路レベル雑音での交点は約 0.19〜0.22% である。** 本番データの charge 交点は $L=5$–7 で 0.218%、$L=7$–9 で 0.192% と下がっている。$L=3$–5 は曲線がほぼ重なり交点が定まらない。各点 $10^4$ ショットでは交点付近の統計誤差が大きく、ショット数を増やした再計算が必要である（R1-5）。この値はネイティブ CCZ（ゲート後に各量子ビット独立の $\mathcal{D}_1(p)$）を仮定したもので、$T$ ゲート分解の内部の故障は含まない。故障表から求めた一次の係数では、dressed チェックの結果の反転率は約 $6.4p$ であり（以前の研究の集約モデルでは $p$）、回路レベルの閾値が低い主な理由と考えられる。

**(4) 符号容量型の交点は 9〜10% の範囲にあるが、$L$ への依存は未確定である。** 本番データでは 9.24%→9.54%→10.15% と上がっているが、交点区間は広く（$L=7$–9 で 9.53–10.61%）、試行計算（9.37%→9.50%→9.59%）とも完全には一致しない。曲線の交わる角度が浅いことによる統計的な揺らぎの可能性が高いが、現在のデータで「安定している」とまでは言えない（R1-4）。なお、この「符号容量型」は測定誤りなし・雑音 1 ラウンドであり、以前の研究の "depolarizing"（測定誤りあり、$R=L$。実質的に現象論的雑音と同じ物理）とは別のモデルである。以前の研究の定義に合わせて v6/v7 のエンジンで計算すると交点は 2.18%、2.07%（合算指標）であったと報告されている［試行値］。

**(5) 非可換性（dressing）の効果。** 試行計算の対照実験（表 7）からは、次の傾向が読み取れる［試行値］。

* 現象論的雑音では、dressing を外すと交点は約 2.7%（$L=7$–9、9–11）で、D4 の約 1.9〜2.0% より 3 割ほど高い。同じプロトコル・雑音・復号器での比較なので、この差は dressing（dressed 測定のバックアクションと論理位相を含む）がもたらすコストの直接の目安になる。ただし交換子だけを独立に操作した実験ではない。
* 回路レベル雑音では、dressing を外した回路には CCZ ゲートそのものとその故障箇所がないので、差（0.4% 超 → 約 0.2%）は「非可換性のコスト」ではなく「dressed 測定回路とそれを除いた回路の性能差」である。
* 旧研究の近似（独立な $Z$ 注入）を同じプロトコルに入れても D4 の曲線は再現できない。現象論的雑音では同じ $p$ での失敗率が大きく違う（$p=1.8\%$, $L=3,5,7$ で 0.20, 0.15, 0.12 に対し D4 は 0.14, 0.10, 0.08）のに、交点はたまたま近い。回路レベルでは交点を約 1.8 倍高く見積もる。

これらの結論を論文で述べるには、対照実験を本番の設定（$L\ge7$ を含み、ショット数を増やしたもの）で実行する必要がある（R1-2）。

**(6) 符号容量型でもランダムな dressed 測定結果が生じる。** 既存の原稿（v8）は「測定が完全なら JIT がすべてのフラックスを dressed 測定の前に除くので、再ランダム化は起こらない」と述べているが、本番データでは符号容量型でもランダムな結果（再ランダム化を含む）が観測されている（第 4.4 節）。原因の候補は二つある。一つは、JIT の未来境界の重みが測定誤り 0 でも有限（`_llr(0)=30`）なので、離れた事象が保留されうること。もう一つは、誤りと補正が作る閉路が dressed 安定化子の積ではなく bare な $X$ 星の積になり、CZ 型の残差が状態に残ること（第 2.3 節）。現在の出力には「dressed 層の直前にフラックスが残っていたか」の記録がないので、どちらが主因かは判定できない。原稿の記述は修正が必要である（R1-3）。符号容量型で dressing の有無による交点の差が小さい（表 7）こと自体は、この点とは別に試行値として観測されている。

**(7) 以前の研究との差。** 以前の研究の値（2.6%、2.4%、0.62%）との違いは、非可換性の厳密な扱いだけでなく、雑音モデルの定義（特に符号容量型の測定誤りとラウンド数）、JIT によるフラックスの実時間補正、回路レベル雑音の故障箇所、初期状態・終了処理・論理量・失敗率の分母の変更が重なったものであり、差の全量を一つの要因に帰することはできない。

**(8) この研究で言えないこと。** 得られた値は、(a) 特定の論理状態（一方向の 3 色ホロノミーの重ね合わせ）への忠実度に基づく条件付きの charge 指標であり、$\mathbb{D}_4$ 符号空間全体（トーラス上で 22 次元）の任意の論理チャネルの保証ではない。(b) 理想的な初期状態・終了処理を仮定した記憶実験である。(c) 復号器は最適化しておらず、閾値は「このプロトコルと復号器に対する値」である。(d) 交点は記述的な推定であり、有限サイズスケーリングによる外挿ではない。

## 5. 研究 2：code switching の論理誤り率

### 5.1 目的とプロトコル

研究 2 は、可換な通常の表面符号（folded surface code）の初期状態から出発し、物理誤り率 $p$ の雑音の下で $\mathbb{D}_4$ 符号に切り替え（switch-in）、理想的な論理 $T^\dagger$（$U=WV$）を作用させ、表面符号に戻す（switch-out）一連の流れを経た後に、「正しく論理 $T^\dagger$ がかかった状態」に復号できなかった割合 $P_L$ を、符号距離 $d$ と $p$ の関数として求める。研究 1 と同様に、隣り合う $d$ の曲線の交点も求める。

幾何（`TriangleCode`）は [1] の Fig. 4 に従う $(d+1)\times(d+1)$ 頂点の正方格子パッチで、$d$ は 1 辺の正方形の数である。[1] の Fig. 4 で単一量子ビット $Z$ 安定化子によって固定される量子ビット（上辺の $b$、左辺の $r$、$\mathcal{L}_{rb}$ の辺の $g$）は理想的な $|0\rangle$ として除いている。$\mathcal{L}_{rb}$ の頂点の $X$ 型生成元は赤と青を組にした `rb` 生成元（CZ dressing を含む）とし、$Z$ 検査と可換でない 2 つの角の組は除く。論理 $Z$ は [1] の補足資料 Fig. 6 の接合点を持つ形を使う。

1 ショットの手順（`ShotRunner.run`）は次のとおりである。

1. 初期状態：FSC（赤・青）の論理 $|+\rangle$、緑は $|0\rangle$（Pauli 安定化子状態）。
2. **switch-in**（$R_{\rm in}=d$ ラウンド）：各ラウンドで全量子ビットに $\mathcal{D}_1(p)$、全ての $Z$ 検査（結果を確率 $p$ で反転）、赤青と緑の JIT フラックス復号と $X$ 補正、dressed $X$ 生成元の色層の順（既定 r→g→b）の測定（結果を確率 $p$ で反転）。
3. **switch-in の終わり**（`switch_in_boundary`）：
   * `ideal`：$U$ の直前に、無雑音の $Z$ 検査と無雑音の dressed $X$ 検査を 1 ラウンド置き、その完全なシンドロームでフラックスを閉じ電荷を後始末する。$U$ は（論理誤りを除けば）完全な $\mathbb{D}_4$ 符号状態に作用する。
   * `noisy`：完全ラウンドを置かない。JIT が保留したフラックスは補正されないまま $U$ に入り、電荷は最終層が未来境界で終われる復号器で推定して後始末する。
4. 電荷の後始末：赤・青は時空 MWPM、緑は最終シンドロームの推定と空間的なペアリング。
5. ケースに応じて：`in_only` はここで $\mathbb{D}_4$ 符号として理想的に読み出して評価（目標 $|+\rangle_{\mathbb{D}_4}$）、`in_out` は $U$ なしで次へ（目標 $|+\rangle$）、`in_T_out` は理想的な $U$ を作用（目標 $T^\dagger|+\rangle$）。
6. **switch-out**：全量子ビットに $\mathcal{D}_1(p)$ を 1 回、緑の単発 $Z$ 測定（結果を確率 $p$ で反転）、緑のフラックスの空間復号、緑の補正 $S^g_X(\lambda)$ の作用。
7. 表面符号（赤・青）の $R_{\rm out}=d$ ラウンドの雑音のある測定と 1 回の完全ラウンド、時空 MWPM による $X$・$Z$ 補正。
8. 論理評価（第 3.3 節）：出力を $\{I,X,Y,Z,S,\text{collapsed}\}$（と `in_only` の flux_D4）に分類し、$P_L=1-P(I)$。

$P_L$ は「最終状態が目標状態そのものか」で判定するマジック状態準備の失敗率で、入力は $|+\rangle$ に固定している。任意入力に対する論理 $T$ ゲートの誤り率や平均の不忠実度とは別の量である（後者は `mean_infidelity_excl_fluxD4` 列に記録される）。

### 5.5 考察

**(1) Pauli proxy 法で code switching 全体を厳密に標本化できた。** 研究 2 の主な成果は、非 Clifford な switch-in の測定、transversal な非 Clifford ゲート $U$、測定に依存する分岐反転補正を含む code switching プロトコル全体を、[2] の方法で厳密に標本化し、その正しさを総当たり計算と独立な厳密エンジンの両方で軌道ごとに確認したことである。1 ショットの計算時間は $d=7$ で数十 ms で、$d$ の多項式で増える。

**(2) ideal 境界の交点は約 2.4〜3.0% で、$d$ とともに下がっている。** $d=3$–5 の 2.97% から $d=5$–7 の 2.41% へ 0.56 ポイント下がっており、研究 1 と同様に有限サイズのドリフトが大きい。この値から漸近閾値を述べることはできない。研究 1 の現象論的雑音の交点（約 2.0〜2.2%）と近い値であるが、研究 2 の $P_L$ はフラックス側・電荷側の両方の失敗と switch-out・表面符号の段階の失敗を含み、トーラスではなく境界のあるパッチで、$\mathbb{D}_4$ 相のラウンド数も $d$ に固定されているので、同じ量の閾値として比べることはできない（第 7.2 節）。

**(3) ideal は楽観側の基準である。** ideal 境界は、「switch-in の論理失敗」と「switch-out（と後続の誤り訂正）の失敗」を $U$ の位置で理想的に切り離した和を測っており、ガジェットごとの性能を比べる基準としては筋が通っている。しかし実機では $U$ の直前に無雑音の測定はできず、$U$ が作用する時点でデータには未検出の誤りが残る。残った $X$ 誤りは $W$ を通って S・CZ 型の Clifford 誤りに変わり、残った緑の電荷は $V$ を通って $e_g\to e_{rgb}$ と広がる。これは code switching 方式そのもののコストであり、ideal ではこれが構造的に 0 になる。したがって、実用性を議論するには noisy 境界の結果が必要である。

**(4) noisy 境界の本番計算は未実行である［修正待ち］。** README_v3 には、以前の版（v1）の試行計算として、noisy 境界では交点が約 1.9%／1.8%、有効距離が約 1 下がる、という値が記載されているが、そのデータは作業フォルダにない。また v3 の noisy 境界、`in_only`、`in_out` の本番計算も作業フォルダにない（R2-1）。本来はここで「ideal と noisy の比較から、$U$ を挟むことのコストを定量化する」予定であったが、現在のデータからは述べられない。なお README_v3 が指摘するとおり、現在の noisy は $U$ の前後で復号窓を切り離した復号器での値であり、実際の性能に対して悲観側である（$U$ をまたぐ復号窓は今後の課題）。実際の性能はおおむね ideal と noisy の間にあると予想されるが、これは予想であり、現在のデータが示すものではない。

**(5) 前提の範囲。** 雑音は現象論的（データの $\mathcal{D}_1(p)$ と測定結果の反転）だけで、回路レベル雑音（dressed チェックの測定回路）は扱っていない。$U$、緑の補正 $S^g_X(\lambda)$、初期化、最終の読み出しは理想、switch-out の $Z^g$ 測定は単発である。$d$ はパッチの 1 辺の正方形の数であり、この作業フォルダの中では、$\mathbb{D}_4$ 相を含むプロトコル全体の実効的な距離が $d$ であることは確認していない（R2-4）。

## 6. 研究 3：code switching と 15-to-1 魔法状態蒸留の資源比較

### 6.1 目的と問題設定

物理誤り率 $p$ と要求される出力誤り $\varepsilon_{\rm target}$ を固定したとき、論理 $T$ 魔法状態（両方式とも実際には $T^\dagger|+\rangle_L$）を 1 個作るのに必要な**時空間体積**（物理量子ビット数 × 時間ステップ数）が小さいのは、

* **Kobayashi 方式**：FSC → $\mathbb{D}_4$ 符号への code switching → transversal $U$（論理 $T^\dagger$）→ FSC への復帰 [1]

### 6.3 Kobayashi 方式の回路

`D4SwitchingCircuit` は次のブロックからなる（$\kappa=1$ のとき）。

* **S0**：FSC のデータを $|+\rangle$ に初期化し、FSC の全検査を $d$ ラウンド（$|+_L\rangle$ の準備。準備法は [1] に記述がなく本研究の構成）。
* **S1**：緑を $|0\rangle$ に初期化し、$\mathbb{D}_4$ の全安定化子を $d$ ラウンド。各ラウンドは Pauli $Z$ 検査 → 実時間の flux 補正 → $X$ 型 Clifford 安定化子の順。最後に $Z$ 検査だけのラウンドを 2 回（v5.2 の改良）。
* **U**：$U=WV$（CNOT、CS、CS$^\dagger$、$T^\dagger$）。
* **SO**：緑を $Z$ 基底で読み出し（1 ステップ）、復号した結果から補正の CZ を固定の層スケジュールで適用（全ての $d$ で 1 層）。
* **S4**：FSC の全検査を $d$ ラウンド。
* **FIN**：雑音なしの FSC 1 ラウンド（論理誤りの評価用。時間には数えない）。

$X$ 型 Clifford 安定化子は、補助量子ビット 1 個（$|+\rangle$）を制御とする CNOT（$X$ 部分）と CCZ（CZ 部分）で測る（本研究の構成で、理想射影測定であることを検証 V9 で確認）。1 ラウンドのステップ数は $\mathbb{D}_4$ の $Z$ 検査 6、$X$ 型安定化子 28、FSC 14、$U$ 5 である。量子ビット数は $12d^2+4d-1$、時間ステップ数は $62d+21$、体積は $632d^3+454d^2+8d-14$ で、$d=3..11$ で回路から直接数えた値と多項式が厳密に一致する（$d=3,5,7,9$ の体積は 21,160、90,376、239,064、497,560）。FSC のラウンドを検証済みの並列スケジュール（8 ステップ）で数えた場合の時間は $50d+20$、体積は $536d^3+398d^2+16d-13$ で、時間・体積だけの感度として示す（その誤り率はシミュレーションしていない）。

フィードフォワードの $X$ 補正（flux 補正、switch-out 後の補正）は、雑音なし・時間 0 の Pauli 層として適用する（理想化）。

### 6.6 Litinski 方式のモデルと表面符号の較正

Litinski 方式は [6] の誤り予算モデル（蒸留回路を 5 論理量子ビット上の $Z$ 型 $\pi/8$ 回転の列とし、各回転の後に $P_{\pi/2}$・$P_{\mp\pi/4}$ 型の誤りが起きる。5 量子ビットの密度行列を厳密に計算し、事後選択後の出力不忠実度と成功確率を得る）を、公開コードを読んで再実装したもので、公開値 8 件を再現する（N6）。GoSC の配置（11 tile × 11τ、225-to-1 の 176 tile × 15τ）への当てはめには、補助領域の tile 数などの仮定を含む。入力の魔法状態の誤りは確率 $p$ とした。

パッチの論理誤り率は、[5] の式 $p_L=0.1(100p)^{(d+1)/2}$ を使わず、同じ雑音モデル（6 ステップ／ラウンド）で Stim の回転表面符号メモリ回路をシミュレーションし、$p_L=A(p/p_{\rm th})^{(d+1)/2}$ を $p\le0.004$ の点に当てはめた（$d=3..11$、$p=0.002..0.006$）。結果は A：$A=0.079$（0.077–0.082）、$p_{\rm th}=0.0085$（0.0084–0.0086）、B：$A=0.040$（0.038–0.042）、$p_{\rm th}=0.0119$（0.0117–0.0121）である（括弧は 16–84% 範囲）。$p\le10^{-3}$ への外挿は同じ関数形を仮定する。

なお、同じ雑音パラメータを使っても比較は対称ではない。Kobayashi 側は回路全体のモンテカルロ、Litinski 側はメモリの論理誤り率を入れた解析的な誤り予算であり、格子手術や蒸留器全体は回路レベルでシミュレーションしていない。

### 6.7 資源比較の結果

#### 6.7.1 比較ノートのモデルによる結果と、その問題点［修正待ち］

比較ノートは、第 3.7 節のモデル $\varepsilon_K=\varepsilon_{\rm bulk}+W$ を当てはめ、要求誤りを満たす最小の $d$ を $d=3,5,\dots,61$ の中から探し、その体積を Litinski 方式の候補集合内の最小体積と比べる。窓の項 $W$ は「$d=5$ には単一故障の一次の寄与が残り、$d=7$ にはない」（N5）という理由で $d\ge7$ のデータだけに当てはめる（`main`）。当てはめの結果は、$p=3\times10^{-4}$ で $W/p=0.48$（B）、9.2（A）、$\gamma=2.43$（B）、3.08（A）、bulk の距離 2 ごとの減少率は A 4.7 倍、B 6.6 倍である［確定（モデルの値）］。

このモデルによる比較の結果（`results/cost_comparison.csv`）は、要求誤り $10^{-4}$ で B・$p=10^{-4}$ が $d=3$・**0.54 倍**、B・$p=2\times10^{-4}$ が $d=5$・1.6 倍、A・$p=10^{-4}$ が $d=7$・4.2 倍（unresolved）、他は全て「届かない」である。既存の README と methods.md はこの「0.54 倍」を、Kobayashi 方式が有利になりうる領域の根拠として挙げている。

しかし、**B・$p=10^{-4}$・要求 $10^{-4}$ で選ばれた $d=3$ は、直接シミュレーションした値と矛盾する。** モデルは $d=3$ で $\varepsilon_K\approx3.3\times10^{-5}$ と予測するが、同じ条件の本来のシミュレーションの値は $4.58\times10^{-4}$（433,200 ショット、失敗 200 件、標準誤差約 $3\times10^{-5}$）であり、要求 $10^{-4}$ を 4.6 倍上回る。N5 の一次の係数（$c_1=4.16$、$\varepsilon_K\approx4.2\times10^{-4}$）とも一致する。原因は、窓の項を $d\ge7$ のデータだけに当てはめて $d$ によらないと仮定したモデルを、当てはめの範囲の外の $d=3$（窓の単一故障の寄与が大きい）に使ったことにある。ブートストラップは同じモデルの中での不確かさしか評価しないので、この誤りを検出しない（この行の `frac_reached` は 1.0）。同じ問題は、窓の項の別の当てはめ方（`W5`、`altW`）、Kobayashi 方式が同じ体積に収まるのに必要な改善倍率（IV-3 の `required_improvement`。$d_{\max}=3, 5$ の行）にも及ぶ（R3-1）。

したがって、「アイドル雑音なし・$p=10^{-4}$・要求 $10^{-4}$ で Kobayashi 方式が 0.54 倍の体積で済む」という結論は、現在の実装からは導けない。本来は、モデルを $d\ge7$ に限って使うか、シミュレーションした $d\le9$ では直接のデータ（と統計的な上限）で要求を満たすかを判定するよう比較ノートを修正したうえで、改めて最小体積の比を述べる予定である。

#### 6.7.2 シミュレーションした $d\le9$ のデータから直接言えること［確定］

修正を待たずに、シミュレーションした $d\in\{3,5,7,9\}$、$\kappa=1$ の本来のシミュレーションのデータ（表 13）だけを使って、要求を満たす最小の $d$ と体積比を求めると次のようになる。

#### 6.7.3 窓の雑音を除いた診断

窓の雑音を 0 にした診断（bulk のみ）のモデルでは、要求 $10^{-6}$ 以下で Kobayashi 方式の体積は Litinski 方式の B で 1.8〜13 倍、A で 2.7〜39 倍（$p\le5\times10^{-4}$。$p=10^{-3}$・A は届かない）、FSC を 8 ステップで数えると B で 1.5〜11 倍になる［確定（モデルの値）］。選ばれた $d$ の多くは $d>9$ や quiet の最小の $p$（$3\times10^{-4}$）未満への外挿である。要求 $10^{-4}$ の診断値（B で 0.37〜9.6 倍）には、第 6.7.1 節と同じく $d=3$ でのモデルの使用が含まれ、特に $p<3\times10^{-4}$ では $p$ 方向の外挿でもあるので、比較の根拠には使わない。診断は「窓の誤りが無かったら」という仮想的な値であり、最適な復号器の性能の上界でも下界でもない。

### 6.8 考察

**(1) Takada らの方法で、回路レベル雑音の code switching 全体を厳密に標本化できた。** CCZ ガジェット、CS、$T^\dagger$、測定に依存する補正 CZ を含む回路（$d=9$ で 1,007 量子ビット）を、各ショット 1 本の Clifford 回路として実行し、379 万ショットを標本化した。適用条件は $L\le9$ で確認し、$L=1,2$ では真の非 Clifford 回路と完全に一致した。これは、[2] が今後の応用として挙げた twisted quantum double 型の魔法状態準備プロトコルの回路レベル評価の、一つの具体例になっている。

**(2) 回路の選択が誤りの床を決める。** $U$ の直前の $Z$ 検査ラウンドの数という一見小さな選択で、単一故障の一次の係数が約 1/10 になった（B, $d=5$：$3.1\to0.27$）。残る単一故障は、B では $\mathbb{D}_4$ 相最後の $X$ 型ラウンドの CCZ ガジェット内の故障、A では $U$ 直前の 2 回目の $Z$ ラウンドの故障が主である（表 12）。既存の文書は「残る単一故障は全て最後の $X$ 型ラウンドの CCZ ガジェット内」と書いているが、これは B についてのみ正しい（R3-4）。flag 量子ビットなどの耐故障な測定ガジェットや、$U$ をまたぐ復号窓の設計で改善できる可能性があるが、試していない。

**(3) 現在の実装では、15-to-1 蒸留の方が小さい体積で済む。** 第 6.7.2 節のとおり、データから直接言える範囲では、評価した全ての条件で Litinski 方式の体積が小さい。主な理由は、(a) 切り替えの窓に $d$ で抑えられない 2 次以上の誤りが残ること、(b) $\mathbb{D}_4$ 相の $X$ 型安定化子のラウンドが 28 ステップと長く、雑音の位置が多いこと（体積 $\approx632d^3$）、(c) アイドル雑音のある場合（A）では待ち時間の雑音が大きいこと、である。

**(4) この結論の範囲。** 結果は「本研究で構成した回路・スケジュール・復号器と仮定の下でのベンチマーク」であり、最適化された Kobayashi 方式に対する一般的な優劣を示すものではない。結論を変えうる要因として、窓の 2 次の誤りを除く復号・回路（[3] の JIT 復号器、CCZ ガジェットの flag 化など）、回路レベルの誤りモデルを持つ flux 復号器（並列スケジュールを使えるようにする）、CCZ の実際の誤り率（実機では 2 量子ビットゲートより悪い可能性が高い）、FSC → 通常パッチの変換と Litinski 側の状態注入（どちらも未計上）、Litinski 側を回路レベルでシミュレーションした場合との差、がある。資源の計数にも、過小評価の要因（変換、$X$ 補正の理想化、注入）と過大評価の要因（最適化していないスケジュール）が両方ある。

## 7. 総合考察

### 7.1 3 つの研究の関係

3 つの研究は、$\mathbb{D}_4$ 符号の性能評価を「符号そのもの（記憶実験）」→「code switching による論理ゲートのガジェット（現象論的雑音）」→「回路レベル雑音での資源比較」と段階的に広げたものである。方法の面では、次の流れがある。

1. 研究 1 で、dressed 測定の非可換性を厳密に扱う表現（twisted-frame）を独自に構成し、以前の研究の Clifford サロゲートが表せなかった再ランダム化を含めて閾値を求め直した。
2. 研究 2 では、Takada らの Clifford-stabilizer simulation（Pauli proxy 法）[2] を採用し、境界のあるパッチ、switch-in・switch-out、transversal な非 Clifford ゲートを含むプロトコル全体に拡張した。その正当化では、研究 1 と同系統の twisted-frame エンジン（v1）と Pauli proxy エンジンが、同じ入力に対して 260 万以上の出力で全て一致した。二つの独立な厳密法の一致は、両者の正しさを互いに支える。
3. 研究 3 では、[2] の回路レベルの Algorithm 2 で、CCZ ガジェット・CS・$T^\dagger$・測定依存の補正 CZ を含む回路全体を厳密に標本化し、魔法状態蒸留との比較に使った。

Takada らの方法の意義は、本研究の文脈では次のようにまとめられる。(i) 非 Clifford な測定回路と transversal 非 Clifford ゲートを含むプロトコルを、近似（例えば $T$ 状態を $S$ 状態で代用する proxy や、独立な $Z$ 雑音による dressing の置き換え）なしに標本化できる。(ii) 標本化の費用は系の大きさの多項式で、Stim の安定化子シミュレーションとほぼ同じ構造で実装できる。(iii) 適用条件（Definition 1, 2 と Sec. VIII の条件）は有限のサイズで代数的に確認でき、小さいサイズでは状態ベクトルとの直接照合もできる。研究 2・3 は、これらの性質を $\mathbb{D}_4$ code switching で具体的に確かめた例になっている。

### 7.2 研究間の数値は直接比べられない

3 研究の「閾値」や誤り率は、次の点で異なる量である。

* **研究 1** の値は、トーラス上の記憶実験の、flux 成功に条件付けた電荷側（$X$ 安定化子側）の失敗率の交点である。初期状態・終了処理は理想で、ラウンド数は $R=L$（符号容量型は $R=1$）。
* **研究 2** の値は、境界のあるパッチでの code switching 全体の、目標状態が得られなかった割合（flux・charge・switch-out・表面符号の全ての失敗を含む）の交点である。$\mathbb{D}_4$ 相は $d$ ラウンドで、$U$ 直前の境界は ideal（完全ラウンド）である。
* **研究 3** の値は、回路レベル雑音での出力不忠実度で、閾値ではなく特定の $(d,p)$ での値である。雑音の定義（CCZ の 3 量子ビット脱分極、アイドル雑音）も研究 1 の回路レベル雑音と異なる。

例えば研究 1 の現象論的雑音の交点（約 2.0〜2.2%）と研究 2 の ideal 境界の交点（約 2.4〜3.0%）は近い値であるが、これを「同じ閾値が二つの方法で再現された」と読むことはできない。また、研究 1 の回路レベル雑音の交点（約 0.2%）と研究 3 で $\varepsilon_K$ が $d$ とともに下がる範囲（A では $p\lesssim3\times10^{-4}$）も、回路・雑音・復号器・プロトコルが異なるので比較できない。

### 7.3 共通の限界

* **有限サイズ**：研究 1・2 とも交点が $L$（$d$）とともに低い $p$ へ動いており、漸近閾値を確定していない。研究 3 は $d\le9$ で、$d>9$ はモデルによる外挿である。
* **復号器**：いずれの研究の復号器も最適化していない。研究 1・2 の JIT 復号器は [3] の方針に沿って本研究で構成したもので、[3] の復号器と同一であることは確かめていない。研究 3 では [3] の本文を参照できず、復号器を独自に構成した。得られた値は「そのプロトコルと復号器に対する値」である。特に研究 3 の単一故障の失敗は、回路・復号器の組で単一故障訂正が成り立っていないことを示している。
* **理想化**：研究 1 の初期状態と終了処理、研究 2 の $U$・補正・初期化・最終読み出し、研究 3 のフィードフォワードの $X$ 補正（雑音なし・時間 0）。
* **CCZ の扱い**：研究 1・3 とも CCZ をネイティブな 1 個のゲートとし、$T$ 分解の内部の故障は扱わない。
* **論理量**：研究 1 は一方向のホロノミーの重ね合わせという特定の論理状態、研究 2・3 は入力 $|+\rangle$ に固定した魔法状態準備の失敗率である。

## 8. 結論

1. **研究 1**：$\mathbb{D}_4$ 符号の dressed $X$ 安定化子の非可換性を厳密に扱う多項式時間の標本化器を構成し、$L=3$ で状態ベクトルとの軌道ごとの一致（測定確率の差 $\le6\times10^{-8}$）と独立標本の失敗率の一致を確認した。JIT フラックス補正の下での $X$ 安定化子側（電荷側）の有限サイズ交点は、各点 $10^4$ ショット・$L\le9$ の本番データで、現象論的雑音 2.25%→2.09%→2.00%、回路レベル雑音（ネイティブ CCZ）0.22%→0.19%、符号容量型 9.2〜10.2% であった。現象論的・回路レベルでは交点が $L$ とともに下がっており、漸近閾値はまだ確定していない。dressing を外した対照実験では現象論的雑音の交点が約 2.7% となり、非可換性に伴うコストが約 3 割である可能性が示されたが、これは試行計算の値であり、本番での確認が必要である。
2. **研究 2**：Takada らの Pauli proxy 法で、表面符号 → $\mathbb{D}_4$ 符号 → 論理 $T^\dagger$ → 表面符号の code switching 全体を厳密に標本化し、総当たり・独立な厳密エンジン・本番経路の再生の 3 種の検証で不一致 0 を確認した。$U$ の直前を理想化した ideal 境界での `in_T_out` の交点は 2.97%（$d=3$–5）、2.41%（$d=5$–7）であり、失敗のほとんどは論理 $Z$ 型であった。$U$ を挟むことのコストを見る noisy 境界の本番計算は未実行である。
3. **研究 3**：回路レベル雑音の code switching 全体を同じ方法で標本化し（379 万ショット）、回路と復号器が 1 個の故障を必ずしも訂正しないこと、$U$ 直前の $Z$ ラウンドを 2 回にすると単一故障の寄与が大きく減ることを示した。シミュレーションした $d\le9$ のデータから直接言える範囲では、評価した全ての条件で 15-to-1 蒸留の方が小さい時空間体積で要求を満たし、最も近いアイドル雑音なし・要求 $10^{-4}$ の場合でも 1.6〜2.3 倍である。既存の文書にある「アイドル雑音なし・$p=10^{-4}$・要求 $10^{-4}$ で 0.54 倍」はモデルの適用範囲外の使用によるもので撤回を要する。

全体として、Takada らの Clifford-stabilizer simulation と本研究の twisted-frame 表現により、$\mathbb{D}_4$ Clifford 階層安定化子符号とその code switching を、非可換性や非 Clifford ゲートを近似せずに大規模に数値評価できるようになった。一方で、得られた性能は回路・復号器の設計に強く依存しており、現在の実装の Kobayashi 方式は、資源の点で魔法状態蒸留を上回っていない。

## 9. 今後の課題

1. **本番計算の追加**：研究 1 の対照実験（none、kappa_injection）と交点付近の高統計の計算（$\ge10^5$ ショット、$L=11$ を含む）、研究 2 の noisy 境界と `in_only`・`in_out` の本番計算、研究 3 の $d\ge7$ の低い $p$ でのショット数の追加。

5. **方法の相互検証**：研究 1 の記憶実験を Takada らの Pauli proxy 法で再実装し、twisted-frame 表現と大きい $L$ で比べる。
6. **研究 2 の回路レベル化**：研究 3 の回路・雑音モデルを研究 2 の閾値計算に使い、回路レベル雑音での code switching の交点を求める。
7. **有限サイズスケーリング**：交点のドリフトを含めた漸近閾値の推定。
8. **費用の未計上分**：FSC から通常の回転表面符号パッチへの変換、状態注入の回路、古典処理の待ち時間。
