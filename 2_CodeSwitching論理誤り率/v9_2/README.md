# 研究2 v9.2：既存本番の指標整理

物理コードは親フォルダの `chsc_switch_v9.py`／`chsc_validation_v9.py` をそのまま参照する。版番号を偽って書き換えたり、既存本番の再開条件を変更しない。v9_1の記録・既存CSVも保持する。

```bash
python 2_CodeSwitching論理誤り率/v9_2/summarize_results_v9_2.py
```

既存6条件×24点、合計144点・288万ショットを再集計し、件数和・P_L・平均不忠実度を検算する。新しい物理Monte Carloは実行しない。出力はこのフォルダの `results/`。in_T_outのidealだけは、v9と同じ物理・既存データであるv3のCSVを使用し、来歴を保存する。

P_L=1−P_Iは目標状態と完全一致しない軌道の割合。研究3の平均不忠実度と同じではない。in_onlyのflux_D4除外平均には条件付けがある。joint復号は赤青の主要履歴をつなぐが、緑の電荷や非Pauli誤りの相関の近似は残る。ideal/noisy差を理想復号下でのU固有のコストと断定しない。
