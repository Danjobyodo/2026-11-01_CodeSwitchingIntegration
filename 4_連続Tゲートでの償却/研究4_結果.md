## 1. 結論

1. **連続実行しても、$T$ ゲート 1 個あたりの誤りは 1 回だけの場合と変わらない**［試行値］。1 サイクルあたりの誤りと 1 回の誤りの比 $m$ は、8 点すべてで区間が 1 を含み、重み付き平均は $m=1.00\pm0.04$。「連続実行で 1 個あたりの誤りが減る」点は 0／8。
2. **サイクルの間の FSC ラウンドを $d$ から 1 に減らしても、誤りは測定できるほどには増えない**［試行値］。誤りの比は 8 点の重み付き平均で $1.02\pm0.03$（個々の点は 0.89〜1.16、どれも 2σ 以内）。1 サイクルの体積は 0.82〜0.87 倍になる。
3. したがって、理論で見積もった償却係数がそのまま使える：$T$ 1 個あたりの体積は研究 3 の **0.83 倍**（gap $=d$）、**0.67〜0.72 倍**（gap $=1$）［確定、回路の数え上げ］。
4. **この償却を入れても、要求誤り $10^{-4}$ の全 10 条件で 15-to-1 蒸留の方が体積が小さい**：code switching ÷ 蒸留は gap $=d$ で 1.32〜8.26、gap $=1$ で 1.10〜6.68［確定した入力（研究 3 の判定と体積）に、試行値で支持された係数を掛けたもの］。データで保証された唯一の条件（B・$p=10^{-4}$・$d=5$）では 2.30 → 1.91（gap $=d$）、1.59（gap $=1$）。
5. 要求 $10^{-6}$ 以下は、償却とは無関係に判定が変わらない（計算した $d\le9$ では到達しない。研究 3）。

**まとめ**：「switch-in の費用を複数の非 Clifford ゲートで償却する」ことで得られるのは体積で 2〜3 割の改善で、蒸留との優劣を逆転させるには足りない。元の方針が期待した優位な条件は、本研究の回路・復号器・比較モデルの範囲では見つからなかった。gap を詰められることは、この研究で新しく分かった（小さいが実在する）改善である。

* 全ての区間が 1 を含む。事前に決めた判定（理論 §2.8）では「$m\approx1$：理論の表がそのまま成り立つ」に当たる。
* 重み付き平均：gap $=d$ で $0.997\pm0.037$（$\chi^2=9.3$、自由度 7）、gap $=1$ で $1.039\pm0.038$（$\chi^2=4.1$、自由度 7）。点の間で $m$ が共通と仮定した参考値である。
* 解釈：1 回の誤りのうち S0（FSC の準備）と最後の FSC ラウンドの寄与は小さく、誤りのほとんどは各サイクルの中（研究 3 が示した切り替えの窓）で生じている。S0 を省いても 1 個あたりの誤りは減らず、前のサイクルの残りが次のサイクルを悪化させる効果も見えない。
* 個々の点の区間は広い（$d=7$ は ±50% 以上）。「$m$ は 0.6〜1.4 の範囲で 1 と区別できない」が正確な言い方で、$m$ が例えば 0.9 か 1.1 かは分からない。

* 1.10 は B・$p=2$〜$3\times10^{-4}$・$d=5$ の値だが、この $d=5$ は研究 3 で「データで棄却されていない」だけで、要求 $10^{-4}$ を満たすことは保証されていない（推定値は要求を超えている）。この試行計算の B・$p=3\times10^{-4}$・$d=5$ の $\varepsilon_{\rm cycle}=(3.2\pm0.6)\times10^{-4}$ も要求の約 3 倍で、**この条件で $d=5$ が要求を満たす見込みは低い**。$d=7$ が必要なら比は 3.5（gap $=d$）、2.9（gap $=1$）になる。

* code switching 側で数えていない費用（データを FSC で持つ費用、通常のパッチとの変換、$H$ の雑音）は比を大きくする方向である。

## 7. 言えないこと・限界

1. **統計**：試行計算は $p\ge3\times10^{-4}$ と $d=3$ が中心で、費用の比較で重要な $p\le2\times10^{-4}$・$d\ge5$ の点が無い（1 点に 100 万ショット以上必要）。そこでの $m$ と gap の効果は**本番待ち**。$m$ が $p$ や $d$ に依存しないことは仮定である。
2. **列の種類**：測ったのは $H$ を挟まない $(T^\dagger)^K$ で、入力は $|+\rangle$。$H$ を挟む実際の列での誤り、$H$ の雑音、他の入力状態は評価していない（Pauli proxy 法では評価できない。理論 §3.2）。
3. **$K\le3$**：1 サイクルあたりの誤りを $K=1$ と $K=3$ の差で定義した。$K$ がもっと大きいときに誤りが蓄積して増える可能性は、$K=3$ までの線形性からは排除できない。
4. **比較の枠組み**は研究 3 と同じ（蒸留側は文献の誤り予算モデル、code switching 側は本研究の回路と復号器）。最適化された code switching に対する一般的な結論ではない。
5. 理論で述べた「1 パッチでは $T$ 1 個分」「CS は 2 倍高い」は、[KZH] のゲート集合と量子ビット数からの議論で、シミュレーションの結果ではない。

## 8. 次にやるなら

1. **本番計算**（`研究4_main.ipynb` の `RUN_MODE='production'`）：B・$p=1$〜$3\times10^{-4}$・$d=5,7$ と A・$p=10^{-4}$・$d=5,7$。目的は $m$ と gap の効果の区間を ±10% 程度にすること。結論（比が 1 を超える）が変わるには、$m$ が 1 より大幅に小さく、必要なサイズが 1 段下がる必要がある。試行値からは見込みが薄いので、優先度は高くない。

4. 1 回の切り替えで $T$ 複数個分を得る構成（CCZ、研究 5 の高い階層）の費用の評価。
