# 研究 5：より高い階層の code switching

元の方針（`2026-11-11` のメモ）は「$\mathbb D_4$ 符号は Clifford 階層の第 3 階層の論理演算ができる。もっと高階層のゲートを実行できる符号に一般化して、より高階層な switching プロトコルを確立したい」。検討して、問いを次のように改めた（理由は `研究5_方針と理論的考察.md` §1）。

> 符号の一般化（twisted $\mathbb Z_2^N$ ゲージ理論、空間 $N-1$ 次元、論理ゲート $R_N=\mathrm{diag}(1,e^{2\pi i/2^N})$）は [KZH] に既にある。[KZH] に無い **(a) $N\ge4$ の code switching の手順、(b) 論理ゲートの境界項を含む一般式、(c) それらの検証** を行い、あわせて **(d) 高い階層に上げると何が重くなり、どういう条件なら役に立つか** を数える。

雑音は入れていない（$N\ge4$ を厳密に標本化する方法が無いため。理論 §5）。したがって閾値や誤り率の結果は無い。

## Colab での実行

1. `研究5_validation.ipynb` を開き、上から全て実行する（既定の `QUICK=True` で 1 分以内、`QUICK=False` で 3〜5 分）。`VALIDATION PASSED` を確認する。
2. `研究5_main.ipynb` を開き、セル 2 の `RUN_MODE` を選んで上から全て実行する。
   * `'quick'`：動作確認（1〜2 分）。
   * `'pilot'`：`results_pilot/` と同じ計算（この環境の CPU 4 コアで約 12 分、メモリ約 3 GB。時間の大半は §2 の $N=4$、$L=(2,2,1)$。`MAX_D` を 20 にすると飛ばして 2 分ほどで終わる）。
   * `'custom'`：セル 2 の `PLAN['custom']` に格子を書く。$N$ は階層、$L$ は長さ $N-1$ のタプル。
3. 出力は `OUT_DIR`（既定 `results_study5/`）：`study5_identity.csv`、`study5_protocol.csv`、`study5_protocol_trials.csv`、`study5_resources.csv`、`study5_levels.csv`、`study5_breakeven.csv`、`study5_verdict.txt`、`fig_study5.png`。

ノートは単独で動く（他のファイルを読み込まない）。必要なのは numpy・scipy・pandas・matplotlib だけで、Stim も GPU も使わない。乱数は `SEED` で決まる。

**大きさの目安**：§1 の検査は状態ベクトルを使わないので、$N=4$ で $L=5$（数秒）、$N=6$ で $L=2$（1 分）まで軽く動く。§2 は次元 $2^D$ の状態ベクトルを持つので $D\le24$ 程度まで（$D$ は §1・§3 の表に出る。$N=4$ の立方体 $L=2$ は $D=44$ で不可）。

## 研究 1〜4 との関係

* 研究 1〜4 のコードは変更していない。研究 5 のコードは独立で、研究 3 からは蒸留工場の体積の表（§5 の損益分岐の見積もりに使う 3 列）だけを埋め込んでいる。
* $N=3$ は研究 2〜4 と同じ符号（$\mathbb D_4$）・同じ手順だが、格子が違う（研究 2〜4 は [KZH] の正方格子、研究 5 は一般の $N$ に共通な Kuhn 三角形分割）。研究 5 の $N=3$ は「同じ手順が別の格子でも $T$ を与える」ことの確認になっている。
* 研究 4 が今後の課題に挙げた「1 回の切り替えで $T$ 複数個分を得る構成」のうち、高い階層（$\sqrt T$）について、雑音の無い範囲の手順と資源を与えたもの。
