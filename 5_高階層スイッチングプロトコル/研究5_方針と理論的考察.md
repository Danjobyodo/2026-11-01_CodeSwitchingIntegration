# 研究 5：より高い階層の code switching — 方針と理論的考察

（2026-11-11。作成：Claude。対象は v11 の研究 1〜4 と [KZH]。計算の結果は `研究5_結果.md`。数値の出所は各節に書く）

---

## 0. 要約

元の方針は「$\mathbb D_4$ 符号は Clifford 階層の第 3 階層の論理演算ができる。もっと高い階層のゲートを実行できる符号に一般化して、より高階層な switching プロトコルを確立したい」だった。検討の結果、方針を次のように改めた。

1. **符号の一般化そのものは [KZH] に既にある。** twisted $\mathbb Z_2^N$ ゲージ理論（空間 $N-1$ 次元）の符号と、その論理ゲート $R_N=\mathrm{diag}(1,e^{2\pi i/2^N})$ である（$N=3$ が $\mathbb D_4$ 符号と $T$、$N=4$ が 3 次元の符号と $\sqrt T$）。「符号を一般化する」ことは新しい研究にならない（§1、§2.1）。
2. **[KZH] に無いのは次の 3 つで、これを研究 5 の対象にした。**
   (a) $N\ge4$ の **code switching の手順**（[KZH] が書いているのは 2 次元の $T$ だけで、3 次元は「期待される」と述べるにとどまる）。
   (b) 一般の $N$ での論理ゲート $U=WV$ の**境界・ヒンジを含む具体的な式**（[KZH] が明示しているのは $N=3,4$ だけ）。
   (c) それらが正しいことの**検証**（[KZH] は連続場の議論で、数値的な確認は無い）。
3. **得られたこと**（詳細は `研究5_結果.md`）。
   * $W$ の閉じた式（式 (3)）を見つけた。各層の項は「前の層の項の半分」という再帰的な形をしていて、その根拠となる恒等式を**解析的に証明**した（付録 A）。
   * 手順を一般の $N$ について書き下し（§3）、$N=2$〜$5$ の小さい格子で、測定結果の乱数と補正を含めた全手順を状態ベクトルで厳密に実行して、出力が $R_N|+\rangle$ になることを確かめた。格子の上の恒等式は $N=8$（空間 7 次元）まで確かめた。
   * $N$ を上げると何が変わるかを整理した（§3.3）。**switch-out の補正が $N\ge4$ では非 Clifford の物理ゲート（$C^{N-2}Z$）になる**ことと、検査の測定に $C^{N-1}Z$ が要ることが、$N=3$ との本質的な違いである。
4. **言えないこと。** 雑音のある場合の誤り率と閾値は、この研究では評価していない。$N\ge4$ を厳密に標本化する方法が今のところ無いためで（§5）、これが高い階層の研究の最大の障害である。したがって「高い階層の code switching が有用か」には答えていない。答えるための**損益分岐の条件**だけを見積もった（§4.4）：$\sqrt T$ を 3 次元の code switching で作ることが Clifford＋$T$ での合成より体積で得になるのは、要求誤り $10^{-4}$ なら $L\lesssim5$、$10^{-6}$ なら $L\lesssim5$〜$7$ で要求に届く場合に限られる。
5. $N\ge5$ は空間 4 次元以上が必要で、局所的な結合の装置では実現できない。物理的に意味のある新しい場合は $N=4$（3 次元、$\sqrt T$）だけである（§4.1）。

**まとめ**：研究 5 は「高階層の switching プロトコルを、雑音の無い範囲で、一般の $N$ について式と手順の水準で確立し、厳密に検証した」ところまでである。耐故障性（復号器、閾値、必要なラウンド数）は未解決で、そこを調べる手段（シミュレーション法）が次の課題になる。

## 1. 元の方針の検討

| 元の方針 | 検討の結果 |
|---|---|
| $\mathbb D_4$ 符号は第 3 階層の論理演算ができる | 正しい（[KZH] Theorem 2。論理 $T$）。 |
| もっと高階層のゲートを実行できる符号に一般化したい | **符号は [KZH] に既にある**（本文の最後の節と SM Sec. III・VII）。twisted $\mathbb Z_2^N$ ゲージ理論、空間 $N-1$ 次元、論理 $R_N$。$N=4$ は安定化子と $W$ が具体的に書かれている。ここを「一般化」しても新しくない。 |
| より高階層な switching プロトコルの確立 | **ここは [KZH] に無い**。[KZH] の手順は 2 次元だけで、$n\ge3$ 次元については「single-shot の code switching が期待される。完全な手順と閾値は今後の課題」と述べている。手順を書き下して検証することには意味がある。 |
| （暗黙の前提）高い階層ほど有用 | 自明ではない。(i) $N$ を 1 上げるごとに空間次元が 1 増える。(ii) 安定化子も補正も階層が上がり、物理ゲートが重くなる。(iii) $R_N$（$N\ge4$）は Clifford＋$T$ で $O(\log(1/\epsilon))$ 個の $T$ で近似できるので、得られるものは定数倍〜対数倍にとどまる（§4）。 |
| シミュレーション | 研究 1〜4 と同じ意味の「雑音付きのモンテカルロ」は、$N\ge4$ ではできない（§5）。**できるのは雑音なしの厳密な検証と、資源の数え上げ**である。それを誠実に行い、できないことは「できない」と書く。 |

研究 4 の結論との関係：研究 4 は「1 回の切り替えで得られる非 Clifford の量は、$\mathbb D_4$ 符号では $T$ 1 個分で、これが費用の下限を決める」と結論し、今後の課題として「1 回の切り替えで $T$ 複数個分を得る構成」を挙げた。$R_4=\sqrt T$ は Clifford＋$T$ で近似すると $T$ が数十個要るので、研究 5 の対象はちょうどこの方向に当たる。

## 2. 階層 $N$ の符号と論理ゲート

### 2.1 [KZH] にあるものと無いもの

| | $N=3$（2 次元） | $N=4$（3 次元） | 一般の $N$ |
|---|---|---|---|
| 符号（安定化子、境界条件） | あり | あり | 概要のみ |
| 論理ゲート $U=WV$ の $V$ | あり | あり | あり |
| $W$ のバルクの項 | あり | あり | あり（SM Sec. III。特別な色を 1 番目に置いた形） |
| $W$ の境界・ヒンジの項 | あり | あり | **無い** |
| code switching の手順 | あり | **無い**（期待のみ） | **無い** |
| 数値的な検証 | 無い | 無い | 無い |

太字の部分が研究 5 の対象である。

### 2.2 設定

記号は [KZH] に合わせる。空間は $n=N-1$ 次元。各辺に $N$ 個の量子ビット（色）があり、$Z$ 基底の値を $\mathbb Z_2$ ゲージ場 $a_c(e)\in\{0,1\}$ と読む。色は「普通の色」$1,\dots,N-1$ と「特別な色」$s$ に分ける（$N=3$ では $(1,s,2)=(r,g,b)$、$N=4$ では $(1,s,2,3)=(r,y,b,g)$）。

* **ねじれ**：$(-1)^{\int a_1\cup a_s\cup a_2\cup\cdots\cup a_{N-1}}$。特別な色を 2 番目に置く（[KZH] の本文と同じ並び）。
* **$Z$ 型安定化子**：各三角形で $\prod_{e\in\partial f}Z^c_e$（ゲージ場が平坦、$da_c=0$）。Pauli 演算子。
* **$X$ 型安定化子**：$S^c_v=\bigl(\prod_{e\ni v}X^c_e\bigr)\times(-1)^{\int(\text{ねじれの式で }a_c\text{ を }\hat v\text{ に置き換えたもの})}$。位相の部分は残りの $N-1$ 色の $C^{N-2}Z$ の積で、$S^c_v$ は**階層 $N-1$** の演算子である（$N=3$：CZ で Clifford、$N=4$：CCZ で非 Clifford）。
* **領域と境界**：$(N-1)$-単体。$N$ 個の面に境界条件を置く。
  * $B_i$（$i=1,\dots,N-1$）：$a_i=0$。
  * $B_N$：$a_s=0$ かつ $a_1+\cdots+a_{N-1}=0$。
  
  $N=3$ では $B_1=\mathcal L_r$、$B_2=\mathcal L_b$、$B_3=\mathcal L_{rb}$、$N=4$ では [KZH] の第 2・第 1・第 3・第 4 境界に当たる。境界の $X$ 型安定化子は、境界条件と可換なものだけを残して切り詰める（$B_i$ では色 $i$ 以外、$B_N$ では普通の色の対 $S^{i}_vS^{j}_v$）。
* **論理量子ビット**：平坦で境界条件を満たす配位は、ゲージ変換を除いて 2 つ。自明な配位が $|\bar0\rangle$、もう一方が $|\bar1\rangle$（[KZH] の主張。本研究では $N\le7$ の格子で次元を直接数えて確かめた）。論理 $Z$ は Pauli $Z$ の弦。

**本研究の格子**：直方体 $[0,L_1]\times\cdots\times[0,L_{N-1}]$ の Kuhn 三角形分割（各単位立方体を $(N-1)!$ 個の単体に分ける標準的な分割。頂点の順序は座標の辞書式順序）。$B_i=\{x_i=0\}$、$B_N=\bigcup_i\{x_i=L_i\}$ とする。これは [KZH] が 2 次元で使った配置（正方形の下辺と右辺を $\mathcal L_{rb}$ にする）の自然な拡張である。**この格子は、全ての $N$ を同じコードで扱うために選んだもので、量子ビット数を最小にする選び方ではない**（斜めの辺がある分、[KZH] の正方格子より多い。§4.2）。

### 2.3 論理ゲート $U=WV$ の一般式（本研究の結果）

$V=\bigotimes_e\prod_{j=1}^{N-1}\mathrm{CNOT}^{(j\to s)}_e$（$a_s\to a_s+\sum_ja_j$）。これは [KZH] のとおり。

$W=e^{i\pi f}$ は対角な演算子で、次の式で与えられる。まず $m-1$ 個の色 $b_1,\dots,b_{m-1}$ と $(m-1)$-単体（頂点 $v_0<\dots<v_{m-1}$、辺 $e_k=(v_{k-1},v_k)$）に対して

$$\alpha_m(b_1,\dots,b_{m-1})=\frac12\,b_1(e_1)\prod_{k=2}^{m-1}\Bigl[b_k(e_k)\,(-1)^{\sum_{j>k}b_j(e_k)}\Bigr]\tag{1}$$

と定める（$b(e)\in\{0,1\}$ は整数として扱う。値は $0,\pm\frac12$）。次に、層の列

$$\Sigma_0=\text{全体}\ \supset\ \Sigma_1=B_N\ \supset\ \Sigma_2=B_N\cap B_2\ \supset\ \cdots\ \supset\ \Sigma_{N-2}=B_N\cap B_2\cap\cdots\cap B_{N-2}\tag{2}$$

を取る（$\Sigma_k$ は $N-1-k$ 次元。向きは、$\Sigma_{k+1}$ を $\Sigma_k$ の境界として誘導する）。このとき

$$\boxed{\;f=\sum_{k=0}^{N-2}\Bigl(-\frac12\Bigr)^{k}\int_{\Sigma_k}\alpha_{N-k}\bigl(a_1,a_{k+2},a_{k+3},\dots,a_{N-1}\bigr)\;}\tag{3}$$

である。$\Sigma_k$ の上では色 $2,\dots,k$ は 0 で、色 $k+1$ は残りの色の和に等しいので（$B_N$ の境界条件）、独立な色は $1,k+2,\dots,N-1$ の $N-1-k$ 個である。

* $N=3$：$f=\int\frac{a_1a_2}{2}-\int_{B_3}\frac{a_1}{4}$。[KZH] の式（CS と、$\mathcal L_{rb}$ の上の $T^\dagger$）。
* $N=4$：$f=\int\bigl[\frac{a_1a_2a_3}{2}-a_1(a_3\cup_1a_2)a_3\bigr]-\int_{B_4}\frac{a_1a_3}{4}+\int_{B_4\cap B_2}\frac{a_1}{8}$。[KZH] の式（CCS、第 4 境界の CT$^\dagger$、ヒンジの $\sqrt T$）と同じ演算子（$\bmod 2$ では cup-1 の項の符号は効かない。検証 V2a）。
* $N\ge5$：**[KZH] には無い。** 式 (1) の符号 $(-1)^{\sum_{j>k}b_j(e_k)}$ が本質的で、[KZH] の SM にある「cup-1 の項を足す」形（符号を $+$ に取る形）のまま半分にして境界に置くと、$N=5$ で成り立たない（最初に試して失敗し、補正を計算機で探して式 (1) に至った。負の対照 V3 の「cup-1 を + で足す」）。

**ゲートとしての中身**：$\Sigma_k$ の 1 つの単体の項は、$N-1-k$ 個の量子ビットに作用する「全部が 1 のとき位相 $\pm\pi/2^{k+1}$」のゲート（符号は同じ辺の別の色の量子ビットで決まる）。制御 $q$ 個・角度 $\pi/2^{j}$ の位相ゲートは階層 $q+j+1$ なので、**全ての層のゲートが階層 $N$** である。

| 層 | 次元 | $N=3$ | $N=4$ | $N=5$ |
|---|---|---|---|---|
| $\Sigma_0$（バルク） | $N-1$ | CS | CCS | CCCS |
| $\Sigma_1=B_N$ | $N-2$ | $T$ | CT | CCT |
| $\Sigma_2$ | $N-3$ | — | $\sqrt T$ | C$\sqrt T$ |
| $\Sigma_3$ | $N-4$ | — | — | $\sqrt[4]{T}$ |

論理作用は $U|\bar m\rangle=e^{2\pi im/2^N}|\bar m\rangle$、すなわち $R_N$（本研究の格子の向きでの符号。[KZH] は $T^\dagger$・$\sqrt T$ と書いていて、向きの取り方で $R_N$ と $R_N^\dagger$ が入れ替わる。物理的な違いは無い）。

### 2.4 式 (3) の根拠

$U$ が符号空間を保つ条件は、ゲージ理論の標準的な議論（[KZH] SM Sec. IV B）では次の「降下」の式になる。普通の色のゲージ群 $\mathbb Z_2^{N-1}$ の群コチェインとして、

* (バルク) $\delta\alpha_N=$（$V$ によるねじれの変化）$\pmod 2$。
* (層 $k\to k+1$) $\alpha_{N-k}$ を $\Sigma_{k+1}$ の境界条件（色 $k+1$ ＝ 残りの色の和）に制限したものが、次の層の項の $\delta$ になる。

本研究では後者について、$\bmod$ を取らない**厳密な等式**

$$\alpha_m(b_1,b_2,b_3,\dots,b_{m-1})\Big|_{b_2=b_1+b_3+\cdots+b_{m-1}}=\frac12\,\delta\alpha_{m-1}(b_1,b_3,\dots,b_{m-1})\tag{4}$$

が成り立つことを証明した（付録 A）。式 (4) を繰り返し使うと式 (3) の係数 $(-\frac12)^k$ がそのまま出る。バルクの式も同じ計算から出る（付録 A）。

**証明したのは群コチェインの水準まで**である。そこから「三角形分割された格子の上で、境界の切り詰めた安定化子も含めて $US^c_vU^\dagger$ が安定化子になる」ことを導く部分は、一般論に頼っていて、本研究では証明していない。代わりに格子の上で直接、数値的に確かめた（§6、結果 §2）。

## 3. code switching の手順（一般の $N$）

### 3.1 手順

[KZH] の 2 次元の手順（SM Sec. V A）を一般の $N$ に書き直す。

0. **Pauli 符号**：普通の色 $1,\dots,N-1$ の $(N-1)$ 次元トーリック符号 $N-1$ 枚を、$B_N$ で貼り合わせた符号（$B_N$ の上で $Z^1Z^2\cdots Z^{N-1}$ が安定化子）。論理量子ビット 1 個。$N=3$ では折り畳み表面符号。データをこの符号の $|\bar\psi\rangle$ に持ち、特別な色を全て $|0\rangle$ にする。
1. **switch-in**：特別な色の $X$ 型安定化子 $S^s_v$（$B_N$ の外の全ての頂点）を測る。結果 $(-1)^{m_v}$ は $\pm1$ の乱数。$m_v=1$ の頂点には電荷 $e_s$ がある。
2. **電荷の処理**：$m_v=1$ の頂点から $B_N$ まで $Z^s$ の弦をかける（その場で消す）か、消さずに Pauli フレームとして記録する。
3. **論理ゲート** $U=WV$。
4. **switch-out**：特別な色を全ての辺で $Z$ 測定する。結果は $a_s=d\lambda$（$\lambda$ は頂点の 0/1。$B_N$ で 0）の形をしている。補正 $\prod_v(S^s_v)^{\lambda_v}$ をかける。特別な色に対しては $X$（または単に初期化し直す）、**普通の色に対しては $C^{N-2}Z$ の積**である。
5. Pauli 符号に戻る。出力は $R_N|\bar\psi\rangle$。2. でフレームに記録した場合は、同じ弦の上の $Z^1\cdots Z^{N-1}$ を Pauli フレームに加える。

### 3.2 なぜ動くか

* $a_s=0$ のとき、普通の色の $S^j_v$ の位相の因子は 1 になる（位相の各項が $a_s$ を因数に持つ）ので、$S^j_v$ はトーリック符号の星型演算子に一致する。したがって手順 0 の状態は、$S^s_v$ 以外の全ての安定化子の $+1$ 固有状態である。
* $S^s_v$ は、平坦な配位の上で他の安定化子と論理 $Z$ の全てと可換。測定は符号空間を階層 $N$ の符号（電荷付き）に射影し、論理情報を壊さない（結果の確率は論理状態によらず 1/2）。
* 電荷は $Z^s$ の弦の端で、$Z^s$ は $W$ と可換、$V$ は $Z^s\to Z^sZ^1\cdots Z^{N-1}$ と写す。したがって**電荷の副産物は、どの $N$ でも Pauli フレームで追える**。
* $U$ は符号空間を保ち $R_N$ として作用する（§2.3）。
* 手順 4 の補正は安定化子の積なので、「$a_s=d\lambda$ への射影の後に補正」は「$a_s=0$ への射影」と同じで、これは論理 $Z$ 基底の振幅を変えない。

これらは定性的な説明で、証明ではない。全手順を状態ベクトルで実行して確かめる（§6）。

### 3.3 $N$ によって変わること

| | $N=3$ | $N=4$ | 一般の $N$ |
|---|---|---|---|
| 空間次元 | 2 | 3 | $N-1$ |
| 論理ゲート | $T$ | $\sqrt T$ | $R_N$ |
| 安定化子の位相の因子 | CZ（Clifford） | CCZ | $C^{N-2}Z$（階層 $N-1$） |
| 検査の測定に要るゲート（補助量子ビットで制御） | CCZ | CCCZ | $C^{N-1}Z$（階層 $N$） |
| $W$ のゲート | CS, $T$ | CCS, CT, $\sqrt T$ | 階層 $N$ |
| 電荷（switch-in の乱数）の副産物 | Pauli | Pauli | Pauli |
| switch-out の補正 | CZ（Clifford） | **CCZ（非 Clifford）** | $C^{N-2}Z$ |
| 1 個の $X$ 誤りが $U$ を通った後 | $X\times$（Clifford の対角） | $X\times$（階層 3 の対角） | $X\times$（階層 $N-1$ の対角） |
| フラックス（$X$ 誤りの症候群） | 点（非 Abel 的エニオン） | 閉じたループ | $(N-3)$ 次元の閉じた膜 |

$N=3$ から $N=4$ に上がるときの本質的な違いは 3 つある。

1. **switch-out の補正が非 Clifford になる。** $N=3$ の補正は CZ で、研究 2・3 では物理的な CZ としてかけた。$N=4$ では測定結果に応じて CCZ をかける必要がある。Pauli フレームでも Clifford フレームでも追えない。補正のゲートが誤ると、Pauli 符号の上に CCZ 型の誤りが残る。
2. **検査の測定が重い。** $S^c_v$ を補助量子ビットで測るには、位相の因子を制御付きにした $C^{N-1}Z$ が要る。$N=4$ では 4 量子ビットゲートの CCCZ、またはその分解である。本研究の格子では、$N=4$ の 1 つの検査は $X$ 14 個と CCZ 6 個（12 量子ビット）からなる（結果 §4）。
3. **フラックスが点でなくループになる。** 3 次元では $X$ 誤りの症候群（$Z$ 型安定化子の破れ）が閉じたループになり、[KZH] はこれによって single-shot の切り替えが可能になると期待している。ただし電荷（$S^c_v$ の破れ）は 3 次元でも点で、測定誤りに対して繰り返し測定が要る。[KZH] 自身が「完全な single-shot の手順には、電荷の誤りも 1 回で訂正する仕組み（ゲージ色符号のような部分系の定式化、または dimensional jump）が要る」と述べていて、未解決である。

## 4. 物理的に意味のある範囲と資源

### 4.1 $N\ge5$ は空間 4 次元以上が要る

階層を 1 上げるごとに空間次元が 1 増える。局所的な結合で実現できるのは 3 次元までなので、**$N\ge5$ は局所的な装置では実現できない**（非局所的な結合があれば原理的には可能だが、量子ビット数は $L^{N-1}$ で増える）。本研究では $N\ge5$ を「式と手順が一般の $N$ で正しいことの確認」として扱い、実用性の議論は $N=4$ に限る。

これは [KZH] の言う「一般化された Bravyi–König の限界」の裏返しである：Pauli 符号では $n$ 次元で階層 $n$ まで、この符号族では $n$ 次元で階層 $n+1$ まで。1 階層ぶん得をするが、次元を増やさずに階層を上げることはできない。

### 4.2 $N=4$ の資源（本研究の格子での数え上げ）

出所は `研究5_main.ipynb` §3（`results_pilot/study5_resources.csv`）。$L$ は立方体の 1 辺の辺の数。

| | $N=3$（2 次元） | $N=4$（3 次元） |
|---|---|---|
| データ量子ビット数 | $9L^2+2L$ | $28L^3+18L^2+3L$ |
| うち Pauli 符号の分 | $6L^2+2L$ | $21L^3+18L^2+3L$ |
| Pauli 符号の距離 $(d_X,d_Z)$ | $(2L+3,\ L)$ | $(4L^2+12L+3,\ L)$（$L\le3$ で確認） |
| switch-in の検査 1 個（内部の頂点） | $X$ 6 個＋CZ 2 個 | $X$ 14 個＋CCZ 6 個 |
| $W$ で 1 量子ビットが関わるゲート数（最大） | 1 | 4 |
| 1 個の $X$ 誤りが $U$ の後に関わる量子ビット数（上界） | 2 | 12 |

* $Z$ 型の論理演算子の最小の重みは $L$ で、これが符号の距離を決める。$X$ 型は 3 次元では膜なので $L^2$ で増える（3 次元トーリック符号と同じ非対称性）。
* 量子ビット数の係数（$N=4$ で 28）は Kuhn 分割の斜めの辺を含む。立方格子の辺だけなら $3L^3$ 本 × 4 色 $=12L^3$ で、2.3 倍少ない。[KZH] は立方格子の上のカップ積で同じ符号を定義できると述べているので、**最適化すれば $12L^3$ 程度になる見込み**だが、本研究では構成も検証もしていない。
* 「$X$ 誤りの広がり」は、$W$ の中で同じゲートに入る量子ビットの数で、誤りの伝播の上界である。$L$ によらない定数だが、$N$ とともに急に増える（$N=5$ で 54）。実効的な距離をどれだけ下げるかは、復号器を含めた評価が要る。

### 4.3 $\sqrt T$ を直接実行できることの価値

$R_4=\sqrt T$ は Clifford＋$T$ では厳密に作れず、近似が要る。精度 $\epsilon$ に必要な $T$ の数は、補助量子ビットを使わない最適な合成（Ross–Selinger）で約 $3\log_2(1/\epsilon)$、repeat-until-success 回路（Bocharov–Roetteler–Svore）で期待値が約 $1.15\log_2(1/\epsilon)$＋定数である。$\epsilon=10^{-4}$〜$10^{-10}$ で数十個〜100 個になる。

研究 4 の言葉で言えば、**1 回の切り替えで得られる非 Clifford の量が、$N=3$ の「$T$ 1 個」から、$N=4$ では「$T$ 数十個分」になる**。これが高い階層の唯一の（しかし大きい）利点である。$N\ge5$ に上げても、$R_5$ を合成する $T$ の数は $R_4$ とほぼ同じなので、利点は増えない。

ただし、$\sqrt T$ がそのまま役に立つ場面（位相勾配、量子フーリエ変換の小さい回転など）がアルゴリズムの中にどれだけあるかは別の問題で、本研究では扱っていない。任意の回転を Clifford＋$T$＋$\sqrt T$ で合成したときに $T$ 数がどれだけ減るかも調べていない。

### 4.4 損益分岐の条件

$\sqrt T$ を 1 個、誤り $\delta$ 以下で実行する費用を比べる。

* **合成**：合成誤り $\delta/2$、$n_T=\lceil3\log_2(2/\delta)\rceil$ 個の $T$、$T$ 1 個の要求誤り $\delta/(2n_T)$。$T$ 1 個の体積は研究 3 の 15-to-1 蒸留の値（`cost_comparison.csv`、シナリオ B・$p=10^{-4}$、要求誤りについて内挿）。
* **3 次元の code switching**：量子ビット数 $=2\times$（データ量子ビット数）。時間と誤り率は**分からない**。

そこで「合成の体積を予算とすると、code switching は何ステップ使ってよいか」を計算し、2 次元の $T$ の code switching の時間（研究 3、$62L+21$ ステップ）で割った（「許される倍率」）。値は `研究5_結果.md` §6。要点は：

* $\delta=10^{-4}$：$L=3$ で約 10 倍、$L=5$ で約 1.4 倍、$L\ge7$ で 1 未満。
* $\delta=10^{-6}$：$L=3$ で約 15 倍、$L=5$ で約 2.2 倍、$L=7$ で約 0.6 倍。
* 量子ビット数を $12L^3$ と楽観的に見積もっても、$L$ が 2 だけ大きいところまで延びる程度。
* 同時に使う量子ビット数は、蒸留工場の 2〜55 倍（$L=3$〜$9$）。

つまり、**3 次元の code switching が体積で得になるのは、$L\approx5$ 以下で要求誤りに届き、かつ時間が 2 次元の場合と同程度で済む場合に限られる。** 研究 3 では、2 次元の $\mathbb D_4$ 符号は $p=10^{-4}$（シナリオ B）で $10^{-4}$ に届くのに $d=5$ が必要で、$10^{-6}$ 以下は計算した $d\le9$ のデータでは保証できていない。3 次元の符号がこれより大幅に良い誤り率を持つ根拠は今のところ無い（検査が重くなる分、悪くなる要因はある。single-shot が成り立てば時間は短くなる）。**したがって、現時点で「高い階層の code switching が有利」と言える材料は無い。有利でないとも言えない。** 判定には 3 次元の符号の雑音下の性能が要る。

この見積もりの限界：合成側は文献の $T$ 数の式と研究 3 の蒸留の体積（文献の誤り予算モデル）、switching 側は量子ビット数だけ。$\sqrt T$ を消費する側の費用（データを 3 次元の符号に出し入れする費用を含む）は数えていない。

## 5. 雑音付きのシミュレーションをしない理由

研究 1〜4 は、非 Clifford な回路を厳密に標本化するために Pauli proxy 法（[Tak] の Clifford-stabilizer simulation）を使った。この方法は**第 3 階層**のための方法である：安定化子が Clifford 演算子で、Pauli 誤りを安定化子で共役しても Pauli 誤り（に Pauli の修飾が付いたもの）に留まることを使う。$N=4$ の安定化子は CCZ を含む非 Clifford 演算子で、$X$ 誤りを共役すると CZ が出てくる。[Tak] 自身が、高い階層の安定化子群への拡張を今後の課題に挙げている。

力ずくの状態ベクトルも届かない。本研究の表現（平坦な配位だけを持つ。$X$ 誤りがあるとさらに増える）でも、次元は $2^D$ で、

| 格子 | $(1,1,1)$ | $(2,1,1)$ | $(2,2,1)$ | $(2,2,2)$ | $(3,3,3)$ |
|---|---|---|---|---|---|
| $N=4$ の $D$ | 7 | 13 | 24 | 44 | 135 |
| 距離 $d_Z$ | 1 | 1 | 1 | 2 | 3 |

である。距離 2 の最小の格子で $2^{44}$、距離 3 で $2^{135}$。距離 1 の格子では 1 個の誤りが論理誤りになるので、雑音を入れても意味のある量が測れない。

加えて、3 次元の非 Abel 的なループ状フラックスの復号器（just-in-time 復号の 3 次元版、または single-shot の復号）は確立していない。

以上から、**$N=4$ の雑音下の誤り率と閾値は、新しいシミュレーション法か、大幅な近似無しには評価できない。** 無理に近似的なモデル（例えばフラックスを Abel 的とみなす）で数字を出すと、根拠の無い結論になるので、行わなかった。

## 6. シミュレーションの設計

雑音は入れない。確かめることと方法は次のとおりで、合否の基準は計算の前に決めた（全て「厳密に成り立つか否か」なので、統計的な判定は無い）。

| 対象 | 方法 | 規模 | 基準 |
|---|---|---|---|
| 式 (4) とバルクの式 | 群コチェインを全ての点（または無作為な点）で評価。位相は $\pi/2^8$ 単位の整数で厳密に扱う | $m\le6$ は全点、$m\le10$ は標本 | 不一致 0 |
| 論理量子ビットが 1 個 | $Z$ 型の条件の解空間の次元を $\mathrm{GF}(2)$ の消去法で数える | $N\le7$ | $k=1$ |
| $X$ 型安定化子が $S^2=1$、互いに可換 | 無作為な平坦配位の上で位相を比べる | 任意の大きさ | 不一致 0 |
| $US_gU^\dagger$ が安定化子 | 同上。全ての生成元 | 任意の大きさ | 不一致 0 |
| $U$ の論理作用 | 配位 $a$ から $Va$ までゲージ変換でつなぎ、位相を集める。配位によらないことも確認 | 任意の大きさ | $\pi/2^{N-1}$ |
| 全手順（§3.1） | 状態ベクトル（平坦な配位の空間、次元 $2^D$）。測定は Born 則で標本化 | $D\le24$ | 忠実度 1 |
| 独立な実装 | 辺の量子ビットを全て持つ状態ベクトル | 15 量子ビットまで | 忠実度 1 |
| 負の対照 | 式の一部や補正を壊す | — | 検査が失敗する |

**表現について**：雑音が無ければ、状態は常に「平坦で境界条件を満たす配位」の重ね合わせである。この空間は、論理値 $m$ と、許されるゲージ変換のビットで座標付けできる（$D=1+$ 生成元の数）。全ての演算子（安定化子、$V$、$W$、$Z$ の弦、$Z$ 測定）はこの空間を保つので、辺の量子ビット（$N=4$、$(2,2,1)$ で 200 個以上）を全て持たなくても厳密に計算できる。この表現が正しいこと（配位の数え方、演算子の実装）は、独立な実装との比較（V5）で確かめる。

**無作為な配位での検査の強さ**：位相の差は配位の低次の多項式で、式に誤りがあれば多くの配位で不一致が出る（負の対照では、壊した式は全て検出された）。ただし「標本で不一致 0」は証明ではない。小さい格子では状態ベクトルで全ての配位を尽くしていて（$U$ の符号空間からの漏れ 0）、こちらは厳密である。

## 7. この研究で分からないこと、今後の課題

1. **雑音下の性能**（最重要）。$N=4$ の switching の誤り率、閾値、必要なラウンド数。そのための厳密または制御された近似のシミュレーション法（[Tak] の方法の第 4 階層への拡張が自然な候補）。
2. **復号器**。3 次元のループ状の非 Abel 的フラックスの復号、電荷の single-shot 訂正の有無。
3. **非 Clifford の補正の扱い**。switch-out の CCZ を、誤りを増やさずにかける方法（補正の範囲を小さくする測定順序、補正を次の操作に吸収する方法など）。
4. **格子の最適化**。立方格子（$12L^3$）での構成と、検査の重みを下げる工夫。
5. **格子の水準での証明**。式 (3) が境界を含めて安定化子群を保つことの証明（本研究は数値的な確認）。
6. **3 次元の符号への出し入れ**。データを 2 次元の表面符号から 3 次元の貼り合わせ符号へ移す方法と費用（dimensional jump）。
7. **$\sqrt T$ の使い道**。アルゴリズムの中での $T$ 数の削減量。
8. **2 次元への埋め込み**。3 次元の符号を (2+1) 次元の時空で模倣する方法（[KZH] が引用する Bombín・Brown の just-in-time の考え方）で、$\sqrt T$ を 2 次元の装置で実行できるか。できれば §4.1 の制約が緩む。

## 付録 A：式 (4) の証明

**記号**　普通の色のゲージ群を $G=\mathbb Z_2^{r}$ とし、$x_c(g)\in\{0,1\}$ を $g\in G$ の色 $c$ の成分（整数とみなす）とする。$G$ の $k$-コチェインは $k$ 個の元の関数で、

$$(\delta c)(g_1,\dots,g_{k+1})=c(g_2,\dots,g_{k+1})+\sum_{i=1}^{k}(-1)^i c(\dots,g_i+g_{i+1},\dots)+(-1)^{k+1}c(g_1,\dots,g_k).$$

1-コチェイン $F_1,\dots,F_p$ のカップ積を $(F_1\cup\cdots\cup F_p)(g_1,\dots,g_p)=\prod_kF_k(g_k)$ とすると、Leibniz 則 $\delta(F_1\cup\cdots\cup F_p)=\sum_k(-1)^{k-1}F_1\cup\cdots\cup\delta F_k\cup\cdots\cup F_p$ が成り立つ（$(\delta F)(g,h)=F(g)+F(h)-F(g+h)$）。平坦な配位では、単体の辺 $e_k=(v_{k-1},v_k)$ の値が $g_k$ で、辺 $(v_{i},v_{j})$ の値は $g_{i+1}+\cdots+g_j$ なので、格子の上のコチェインと群コチェインは同じものである。

色を $c_1,\dots,c_p$ とし、

$$F_1=x_{c_1},\qquad F_k=x_{c_k}\,\chi_k\ (k\ge2),\qquad \chi_k=(-1)^{\sum_{j>k}x_{c_j}},\qquad \pi_k=\tfrac12(1-\chi_k)=\Bigl[\sum_{j>k}x_{c_j}\text{ が奇数}\Bigr]$$

と置く。式 (1) は $\alpha_{p+1}(c_1,\dots,c_p)=\frac12F_1\cup\cdots\cup F_p$ である。

**補題 1**　$\delta F_1(g,h)=2x_{c_1}(g)x_{c_1}(h)$。$k\ge2$ では

$$\tfrac12\,\delta F_k(g,h)=F_k(g)\,\pi_{k-1}(h)+\pi_k(g)\,F_k(h).$$

（証明）$x(g+h)=x(g)+x(h)-2x(g)x(h)$ と $\chi_k(g+h)=\chi_k(g)\chi_k(h)$ から、$\delta F_k(g,h)=F_k(g)(1-\chi_k(h))+F_k(h)(1-\chi_k(g))+2F_k(g)F_k(h)=2F_k(g)\pi_k(h)+2\pi_k(g)F_k(h)+2F_k(g)F_k(h)$。$\pi_{k-1}=\pi_k+F_k$（$\pi_{k-1}$ は $x_{c_k}+\sum_{j>k}x_{c_j}$ の偶奇で、$x+\pi-2x\pi=\pi+x(1-2\pi)$）を使ってまとめる。∎

**補題 2**　$p\ge1$ について

$$\delta\alpha_{p+1}(c_1,\dots,c_p)(g_1,\dots,g_{p+1})=x_{c_1}(g_1)\,\bigl[x_{c_1}-\pi_1\bigr](g_2)\,F_2(g_3)\cdots F_p(g_{p+1}).\tag{A1}$$

（証明）Leibniz 則と補題 1 から、$\delta\alpha_{p+1}=T_1+\sum_{k=2}^{p}(-1)^{k-1}(C_k+B_k)$。ここで

* $T_1=x_{c_1}(g_1)x_{c_1}(g_2)F_2(g_3)\cdots F_p(g_{p+1})$、
* $C_k=F_1(g_1)\cdots F_k(g_k)\,\pi_{k-1}(g_{k+1})\,F_{k+1}(g_{k+2})\cdots F_p(g_{p+1})$、
* $B_k=F_1(g_1)\cdots F_{k-1}(g_{k-1})\,\pi_k(g_k)\,F_k(g_{k+1})\cdots F_p(g_{p+1})$。

$D_k=F_1(g_1)\cdots F_k(g_k)F_k(g_{k+1})F_{k+1}(g_{k+2})\cdots F_p(g_{p+1})$（$F_k$ を 2 回続けたもの）と置くと、$\pi_{k-1}-\pi_{k+1}=F_k+F_{k+1}$ から $C_k-B_{k+1}=D_k+D_{k+1}$（$2\le k\le p-1$）。また $\pi_p=0$ なので $C_p=D_p$。和を $B$ について 1 つずらしてまとめると

$$\sum_{k=2}^{p}(-1)^{k-1}(C_k+B_k)=-B_2+\sum_{k=2}^{p-1}(-1)^{k-1}(D_k+D_{k+1})+(-1)^{p-1}D_p=-B_2-D_2,$$

（交互和が望遠鏡式に消える）。$B_2+D_2=F_1(g_1)[\pi_2+F_2](g_2)F_2(g_3)\cdots=F_1(g_1)\pi_1(g_2)F_2(g_3)\cdots$ なので (A1) を得る。$p=1$ は $\delta\alpha_2=x_{c_1}(g_1)x_{c_1}(g_2)$ で、$\pi_1=0$ として (A1) に含まれる。∎

**命題（式 (4)）**　色 $b_1,\dots,b_{m-1}$ について、$b_2=b_1+b_3+\cdots+b_{m-1}\pmod2$ の部分群の上で $\alpha_m(b_1,b_2,\dots,b_{m-1})=\frac12\delta\alpha_{m-1}(b_1,b_3,\dots,b_{m-1})$。

（証明）右辺は補題 2 を $(c_1,\dots,c_p)=(b_1,b_3,\dots,b_{m-1})$ に使って、$\frac12x_{b_1}(g_1)[x_{b_1}-\pi_1](g_2)F_2(g_3)\cdots F_p(g_{p+1})$。ここで $\pi_1=[x_{b_3}+\cdots+x_{b_{m-1}}$ が奇数$]$、$F_k$ は $b_{k+1}$ の因子で、式 (1) の第 $k+1$ 番目の因子と同じ。左辺の第 2 の因子は $x_{b_2}(-1)^{\sum_{j\ge3}x_{b_j}}=x_{b_2}(1-2\pi_1)$ で、部分群の上では $x_{b_2}=x_{b_1}+\pi_1-2x_{b_1}\pi_1$ だから、$(x_{b_1}+\pi_1-2x_{b_1}\pi_1)(1-2\pi_1)=x_{b_1}-\pi_1$（$\pi_1^2=\pi_1$）。両辺は一致する。∎

**バルクの式**　補題 2 を $(c_1,\dots,c_p)=(a_1,\dots,a_{N-1})$ に使い、$\bmod 2$ を取ると、$x_{c_1}-\pi_1\equiv\sum_jx_j$、$F_k\equiv x_{c_k}$ なので、$\delta\alpha_N\equiv x_1(g_1)\,\bigl(\sum_jx_j(g_2)\bigr)\,x_2(g_3)\cdots x_{N-1}(g_N)$。これは $a_s\to a_s+\sum_ja_j$ によるねじれ $a_1\cup a_s\cup a_2\cup\cdots\cup a_{N-1}$ の変化である。∎

数値的な確認：`研究5_validation.ipynb` の V1（$m\le6$ は全ての点、$m\le10$ は無作為な 200 万点で、整数として不一致 0）。
