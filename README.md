## 状態

* 確定：研究 1 の正当化（$L=3$ の密な計算、$L\le9$ の Pauli proxy との一致）と現象論的・符号容量型の交点（$10^4$ ショット/点）、研究 2 の正当化と本番（288 万ショット）、研究 3 の比較（554 万ショットのデータの再解析）。
* 研究 4（試行値）：連続実行でも $T$ 1 個あたりの誤りは変わらず（比 $1.00\pm0.04$、336 万ショット）、体積は研究 3 の 0.83 倍（間の FSC ラウンドを 1 に詰めて 0.67〜0.72 倍）。要求 $10^{-4}$ の全 10 条件で蒸留の方が安いまま（1.10 倍以上）。
* 研究 5（雑音なしの厳密な検証）：階層 $N$ の論理ゲート $R_N$ の境界項を含む一般式を与え（根拠の恒等式は証明済み）、code switching の全手順を $N=2$〜$5$ で状態ベクトルにより実行して出力 $R_N|+\rangle$（忠実度 1）を確認。格子上の恒等式は $N=8$ まで。雑音下の誤り率・閾値は評価していない（$N\ge4$ を厳密に標本化する方法が無い）。$\sqrt T$（$N=4$、3 次元）が合成より体積で得になるのは $L\lesssim5$ で要求誤りに届く場合に限られる（損益分岐の条件であって、有利という結論ではない）。
* 本番待ち：研究 1 の $10^5$ ショットの本番と対照実験、現在の回路レベル雑音での GPU の正当化、研究 3 の未確定な点の追加ショット。
