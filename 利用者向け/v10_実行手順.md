## 1. 研究 3：比較の再解析（CPU、約 30 分、追加 MC なし）

`3_魔法状態蒸留との比較/noisy_cost_comparison.ipynb` を開き、`DATA_MODE='reference'`、`N_BOOT=200` のまま全て実行する。`results_v10/` と `figures_v10/` を保存する。この環境で実行した結果がリポジトリの `3_魔法状態蒸留との比較/results_v10/` にあり、同じになるはず（ライブラリの版が違うと bootstrap の末尾の桁が変わりうる）。

## 2. 研究 1：現在の回路レベル雑音の正当化（GPU、T4 で数時間）

`1_D4閾値/D4_v10_validation.ipynb` を GPU ランタイムで開く。

1. 設定のセルで `CFG['circuit_noise_preset']='uniform'`、`VCFG['noise_models']=['circuit_level']` にして最後のセルまで実行する（(A)(B)(C) を r と rgb の両方、(D)、(E)）。
2. 期待する結果：(A) 平坦部分空間で非可換な対 0、(B) `PASSED`（確率・忠実度の差が $10^{-6}$ 程度以下）、(C) 密な計算と本番のエンジンの失敗率に系統的な差が無い（$\sum z^2$ と上側確率を見る。1 点だけの外れは多重比較で起こりうる）、(E) `PASSED`。
3. 符号容量型・現象論的は v7 で正当化済み（物理は同じ）。論文に r/rgb 両方の (C) を載せる場合は、別の出力先でこの 2 モデルも実行する。

## 3. 研究 1：本番（CPU、モデルごとに十数時間）

**統合論文（`論文草稿/統合論文_v10/`）に必要なのは `'phenomenological'` の 1 回だけ**（研究 1 は現象論的雑音だけを載せる）。§2 の回路レベルの GPU 正当化と、`'depolarizing'`・`'circuit_level'` の本番は、研究 1 単独の原稿 `研究1_原稿_v10/` 用。

`1_D4閾値/D4_v10_main.ipynb` の定義のセルまで実行し、`CFG['out_dir']` を Drive に設定してから、モデルごとに別のランタイム・別の出力先で：

```python
prod = run_production(noise_models=['phenomenological'], shots=100000)
```

（次に `'depolarizing'`、`'circuit_level'`。各モデルに D4・none・kappa_injection の 3 種が含まれ、$L=3,5,7,9$、交点付近の $p$。）中断しても、同じ設定・同じ出力先で同じセルを実行すれば完了した点は再利用される（設定が違うとエラーで止まる）。交点が掃引の端に近い・交点が出ない場合は `PRODUCTION_P_RANGE` を広げて別の出力先で取り直す。

## 4. 研究 2：再計算は不要

本番（6 条件・288 万ショット）は完了している。環境の確認だけなら `2_CodeSwitching論理誤り率/CHSC_switch_v10_validation.ipynb`（CPU、約 2 分）で `VALIDATION PASSED` を確かめる。$d=9$ を加える場合は main ノートで `CFG['d_values']=[9]` と新しい `out_dir`・seed を指定する。

## 5. 研究 3：未確定な点への追加 MC（CPU、任意）

`3_魔法状態蒸留との比較/D4_noisy_simulation.ipynb` を `QUICK=True` で動作確認した後、`QUICK=False`、`RUN='extend'`、`EXTEND` に対象の点（優先：B・$p=2\times10^{-4}$・$d=7$、A・$p=10^{-4}$・$d=7$）、`EXTEND_SHOTS`（固定の追加ショット数。例えば 1,000,000）を計算の前に決めて実行する。出来た CSV を比較ノートの `results_v10/` に置き、`DATA_MODE='production'` で再解析する（`reference` のままでは追加分は反映されない）。旧データを複製して独立な標本として加えない。
