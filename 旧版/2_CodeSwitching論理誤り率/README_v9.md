## 2. ideal と noisy の意味（v9）

* `ideal`：$U$ の直前に雑音なしの $Z$ 検査と dressed $X$ 検査を 1 ラウンド置き、完全なシンドロームでフラックスを閉じ電荷を後始末する。switch-in と switch-out 以降を $U$ の位置で理想的に切り離した基準（楽観側）。残った誤りが $U$ を通る効果は構造的に 0 になる（v3 の本番で $S$ 型・collapsed が全点 0）。
* `noisy`：完全ラウンドなし。残った $X$ 誤りは $W$（CS, $T^\dagger$）を通って S・CZ 型の誤りになり、緑の電荷は $V$ で $e_g\to e_{rgb}$ と広がる。これは code switching 方式そのもののコスト。v9 では $U$ をまたいで復号を続けるので、v3 の noisy にあった「窓を切ることによる損失」の一部（フラックスと赤青の電荷）は除かれた。緑の電荷は $U$ の前に後始末したままで、その残りは $V$ で赤青の電荷になり、表面符号の側で見える。
* 実用性の議論には `noisy` を使う。`ideal` と並べることで「$U$ を挟むことのコスト」を見積もる。

## 4. 本番の結果（v9.1 の作業で手元の CPU で実行。R2-1）

`chsc_v9_results/` に、v9 のコード・**既定の設定・既定の seed** で計算した結果を置いた（現象論的雑音、$d=3,5,7$、$p$ は 0.8–5% の対数等間隔 8 点、各点 20,000 ショット）。同じ seed なら Colab で実行しても同じ標本になる（v9 の ideal の `in_T_out` が v3 の Colab の本番と全ショット一致することを、$d=3$ の 2 点で確認した）。`in_T_out`・ideal は v3 の本番（`chsc_v3_results/`）がそのまま v9 の値なので再計算していない。比較図 `chsc_v9_ideal_vs_noisy.png`、`chsc_v9_all_cases_<ideal|noisy>.png` はこの v3 の値を含めて作った。数値の表は `chsc_v9_results/summary_tables.md`、実行の記録は `run_logs.txt`。

**有限サイズ交点**（隣り合う $d$ の $P_L$ の log–log 補間、括弧は再標本化の 2.5–97.5%）

| ケース | 境界 | $d=3$–5 | $d=5$–7 |
|---|---|---|---|
| `in_T_out` | ideal（v3 の本番） | 2.97%（2.89–3.10） | 2.41%（2.25–2.54） |
| `in_T_out` | noisy | 2.23%（2.12–2.35） | 1.94%（1.83–2.01） |
| `in_out` | ideal | 3.13%（3.02–3.21） | 2.24%（2.16–2.37） |
| `in_out` | noisy | 2.81%（2.74–2.89） | 2.23%（2.15–2.36） |
| `in_only` | ideal | 2.33%（2.21–2.43） | 1.91%（1.73–2.01） |
| `in_only` | noisy | 2.10%（1.99–2.24） | 1.74%（1.52–1.88） |

**低い $p$ での $P_L$**（$p=0.8\%$）

| ケース | 境界 | $d=3$ | $d=5$ | $d=7$ |
|---|---|---|---|---|
| `in_T_out` | ideal | 0.01105 | 0.00150 | 0.00040 |
| `in_T_out` | noisy | 0.02125 | 0.00775 | 0.00505 |
| `in_out` | ideal | 0.01125 | 0.00155 | 0.00030 |
| `in_out` | noisy | 0.01205 | 0.00205 | 0.00045 |
| `in_only` | ideal | 0.00465 | 0.00085 | 0.00060 |
| `in_only` | noisy | 0.00655 | 0.00200 | 0.00160 |

読み取れること：
1. **$U$ を挟むことのコストが大きい。** $U$ を挟まない `in_out` では noisy と ideal の差は小さい（$d=7$ で 0.00045 対 0.00030）が、`in_T_out` では noisy が ideal の 10 倍以上（$d=7$ で 0.0051 対 0.0004）で、$d=5\to7$ の改善も 1.5 倍しかない（ideal は 3.8 倍）。noisy では $X$・$Y$ 型（不忠実度 1/2）の類が ideal の約 5 倍に増え（全点合計で $X$ 18,291、$Y$ 16,691 ショット。ideal は 3,823、2,960）、ideal では 0 だった collapsed の類（1,527 ショット）が現れる。$U$ の時点で残った $X$ 誤りが $W$（CS, $T^\dagger$）を通って非 Pauli の誤りになる過程と整合する（S の類はどちらも 0）。v9 では $U$ の前後の復号窓は通しにしているので、この差は窓を切ることによる損失ではなく、$U$ の前に完全なラウンドが無いことそのもののコストである。
2. **交点は全てのケースで $d$ とともに下がる**（有限サイズのドリフト）。漸近閾値は述べられない。
3. `in_only` の失敗には $\mathbb D_4$ の理想読み出しでの flux 側の失敗（`flux_D4`）が含まれる（ideal と noisy で同じ数：$U$ の前の $X$ フレームは両者で同じなので、矛盾ではない）。
4. README_v3 にあった v1 の試行値（noisy の交点 約 1.9%／1.8%）は、復号器が異なる（v1 は窓を切る復号）ので直接比べられないが、v9 の `in_T_out`・noisy（2.23%／1.94%）は同程度である（R2-3 は v9 の本番で置き換えた）。

$d=9$ を加える場合や交点付近の統計を増やす場合は、別の `out_dir`（と別の seed）で実行する。
