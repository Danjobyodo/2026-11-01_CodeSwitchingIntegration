# 研究3 v9.2 の統計的方法

## 観測とモデル

各独立ショットの目標状態に対する不忠実度Xは0,1/2,1。保存した n_fail,n_half より n_one=n_fail−n_half、n_zero=N−n_fail を復元する。平均は ε̂=(n_one+n_half/2)/N。表示用標準誤差は二次モーメントから計算する。ゼロ観測のSE=0は、真の誤り率ゼロの保証ではない。

原始データの複製、同じ物理点のseed再利用、カテゴリ件数と不忠実度和の不整合は拒否する。`R0,Rin,Rout` がκとdから定まる現行ノートの規約を前提とする。独自にラウンド数を変えたデータを既存キーだけで混ぜてはいけない。

モデルは quiet のカテゴリ強度を r_h=exp(Xθ_h), r_1=exp(Xθ_1)、noisyを r_j=exp(Xθ_j)+exp(Zφ_j) とし、

    (p_zero,p_half,p_one) = (1,r_h,r_1)/(1+r_h+r_1)
    ε = p_one + p_half/2
    X = (1,(d−7)/2,log(p/10^-4),((d−7)/2)log(p/10^-4))
    Z = (1,log(p/10^-4))  [altWでは(d−7)/2も追加]

として多項分布尤度を最大化する。main窓はd>=7、W5/altW窓はd>=5。quietを先に推定し、その推定を固定して窓を推定する二段階モデルである。再標本化ではquietとnoisyを元の適合確率から多項分布で生成し、quietも再推定するためその標本変動を伝播する。各variantのbootstrapはそれぞれの適合モデルから生成する。

旧版の単一の平均power-law＋Poisson「半失敗数」から構造も変わっている。新モデルも、窓成分の距離依存・bulkと窓の分離などに仮定を置く記述モデルである。bootstrapは実現したNを固定したモデル条件付き近似で、旧MCの停止規則・モデル誤指定・外挿・較正や工場候補選択の全不確かさを包含する保証ではない。

最適化は解析勾配付きL-BFGS-B、複数初期値、係数範囲[-50,50]。成功・有限性・設計行列rank・境界到達を記録する。成功フラグだけで適合の良さを保証せず、カテゴリ別の観測と予測、境界到達、variantによる変化を見る。窓がほぼゼロのカテゴリでは境界解になり得る。失敗したbootstrapを黙って除外しない。

## データ上の保証：停止規則も扱う

旧MCは失敗件数・時間で停止していた。このため固定Nを仮定する区間だけでは、逐次停止後の公称被覆を主張できない。

不忠実度X∈[0,1]、一定の条件付き平均μ、累積和S、ショット数Nに対して、各q∈(0,1)の過程

    M_N(q,μ) = (q/μ)^S ((1−q)/(1−μ))^(N−S)

を使う。指数関数のXに関する凸性から、1ステップの条件付き期待値は高々1になる。qをBeta(1/2,1/2)で混合した非負supermartingaleは

    E_N(μ) = B(S+1/2,N−S+1/2) / [B(1/2,1/2) μ^S (1−μ)^(N−S)]

となる。Sが半整数でも式は有効。Villeの不等式より、`E_N(μ)<M/α` を満たすμの区間は、最大M点について全時刻同時に少なくとも1−αで真の平均を含む（各点にα/M、点間独立は不要）。本ノートは **M=200、α=.05** を事前の最大点数とする。200点を超えたら止める。追加・選択する物理点もこの割当の範囲内で管理する。ショットの平均がドリフトする、重複seedで独立性が壊れる、観測後に物理条件を混ぜる場合にはこの保証を使えない。

参考列には固定NのChernoff/KL区間も出す。E exp(tX)≤1−μ+μ exp(t)に基づき、N kl(ε̂||μ)≤log(2/α)を反転する。これは固定N用で、旧MCの主たる到達保証には使わない。

`data_certified` はconfidence sequenceの上端が要求以下。下端が要求より大きければ棄却、その他は未確定。実測の未確定をモデルで上書きしない。保証された候補サイズより小さい全候補がデータで棄却されない限り、真の最小費用が確定したとはしない。モデルの95%以上のbootstrap複製が要求を満たす場合の `model_supported` は別列で、頻度論的保証ではない。

## 比較の範囲

Kobayashiの物理回路・idealな境界固定・native CCZ・フィードフォワードの理想化等はv9の方法に従う。資源のFSC8感度は費用だけを変える仮想比較で、その誤り率を新たにシミュレーションしたものではない。Litinski側は較正表面符号モデルを使った文献誤り予算の中央値・候補集合の最小で、同じconfidence sequenceを与えたものではない。方式一般の勝敗・故障耐性の証明に解釈しない。
