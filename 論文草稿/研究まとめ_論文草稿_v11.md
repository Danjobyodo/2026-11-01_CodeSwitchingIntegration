## 要旨

Kobayashi、Zhu、Hsin の 2 次元 $\mathbb D_4$ Clifford 階層安定化子符号 [KZH] は transversal な論理 $T$・$CS$ を持ち、folded surface code（FSC）との code switching によって $O(d)$ ラウンドで論理 $T$ 魔法状態を準備できる。その $X$ 型安定化子は CZ で dressed された非 Pauli の Clifford 演算子であり、測定回路は CCZ を含み、フラックス（$X$ 誤り）があると色の異なる dressed 安定化子が実効的に反可換になって測定結果が確率的になる。本研究は、Takada、Bartlett、Williamson の Clifford-stabilizer simulation [Tak] の枠組みで、この符号とその code switching を非可換性や非 Clifford ゲートを近似せずに標本化し、三段階で評価した。

(1) トーラス上の記憶実験を、$\mathbb D_4$ 符号に特化した厳密表現（twisted frame）で標本化した。$L=3$ で密な状態ベクトルと、$L=3$–9 で Pauli proxy 方式の独立な実装と、軌道ごとに測定確率・最終忠実度が一致した。フラックスに条件付けた電荷側の失敗率の有限サイズ交点は、現象論的雑音で 2.25%、2.09%、2.00%（$L=3$–5, 5–7, 7–9）、符号容量型で 9–10% であり、交点はなお $L$ とともに動くので漸近閾値ではない［確定］。回路レベル雑音（ネイティブ CCZ）では約 0.2% である［試行値・本番待ち］。

(2) FSC → $\mathbb D_4$ → 理想的な論理 $T^\dagger$ → FSC の全体を Pauli proxy 方式で標本化し、総当たり・独立な厳密エンジン・本番経路の再生の 3 種の参照と不一致 0 を確認した。$U$ の直前を理想化した境界での交点は 2.97%、2.41%、理想化しない境界では 2.23%、1.94%（$d=3$–5, 5–7）であり、$U$ を挟まない手順では両者の差が小さい［確定］。

(3) 回路レベル雑音の code switching の出力不忠実度を 554 万ショットで評価し、15-to-1 蒸留（Litinski の構成）と時空間体積を比べた。不忠実度 $\{0,1/2,1\}$ の多項分布と、停止規則に有効な信頼列を用いると、データで保証されるのはアイドル雑音なし・$p=10^{-4}$・要求 $10^{-4}$ の $d=5$（体積比 2.30 倍）だけで、要求 $10^{-4}$ の全条件で Kobayashi 方式の体積は Litinski 方式の中央予測の 1.59 倍以上だった。要求 $10^{-6}$ 以下ではデータもモデルも到達を支持しない［確定、本研究の回路・復号器と比較モデルの範囲で］。

## 1. 序論

### 1.1 背景

汎用な耐故障量子計算には Clifford 群の外の論理ゲートが必要で、2 次元の位相的 Pauli 安定化子符号の定数深さの論理ゲートは Clifford 階層の第 2 層に限られる（Eastin–Knill、Bravyi–König）。表面符号で論理 $T$ を実現する標準的な方法は魔法状態蒸留であり、15-to-1 蒸留の格子手術による配置と費用は Litinski [GoSC, Lit19] が詳しく評価している。

### 1.2 Clifford 階層安定化子符号

[KZH] は安定化子群に非 Pauli の Clifford 階層演算子を含む符号を導入した。2 次元の twisted $\mathbb Z_2^3$ ゲージ理論（非可換な $\mathbb D_4$ トポロジカル秩序と等価）に対応する符号は transversal な論理 $T$・$CS$ を持つ。$Z$ 型安定化子は Pauli のプラケット、$X$ 型安定化子は頂点の $X$ の積に CZ を掛けた dressed 演算子である。FSC からの code switching と実時間（just-in-time, JIT）のフラックス補正 [Dav] により、$O(d)$ ラウンドで論理 $T$ 魔法状態を準備できる。

### 1.3 シミュレーション上の困難

1. dressed 安定化子の補助量子ビット測定は CCZ を含み、$U=WV$ は CS・CS$^\dagger$・$T^\dagger$ を含むので、通常の安定化子シミュレータでは扱えない。
2. dressed 安定化子はフラックスのない部分空間でしか可換でない。フラックスがあると色の異なる dressed 安定化子が実効的に反可換になりうり、$A\to B\to A$ と測ると最後の $A$ は確率 1/2 でしか一致しない。さらに、フラックスを補正した後にも状態に CZ 型の残差が残りうり、それも測定結果をランダムにする。シンドロームは誤り配位の決定的な関数ではない。

以前の研究は dressed 検査を可換な bare 検査に置き換え、dressing の効果を独立な $Z$ 雑音として注入する近似（サロゲート）で閾値を見積もったが、2. を表せない。

### 1.4 本研究の方法と構成

3 研究とも、**雑音のある非 Clifford 回路を、標本ごとに同じ測定統計を与える Clifford 回路または等価な有限の代数的表現に写して厳密に標本化する**（§3）。研究 1 はトーラスの記憶実験（§4）、研究 2 は境界のあるパッチの code switching（§5）、研究 3 は回路レベル雑音での資源比較（§6）である。三者の失敗率・距離・雑音・費用の意味は同じではなく、同じ閾値の三通りの測定ではない（§7）。

## 2. 理論的背景

### 2.1 Clifford-stabilizer group と実効的な可換性

[Tak] は Pauli 安定化子と非 Pauli の Clifford 安定化子で生成され、自明でない共通 $+1$ 固有空間を持つ有限群を Clifford-stabilizer group と呼んだ。一般に非可換だが、要素は安定化子部分空間の上で可換である。$\mathbb D_4$ 符号の dressed $X$ 安定化子どうしの群交換子は面の $Z$ の積であり、フラックスのない部分空間で恒等、対応するフラックスがあると $-1$ になりうる。

### 2.2 トーラス上の $\mathbb D_4$ 符号（研究 1）

$L\times L$ の正方格子の各正方形を対角線で分けた三角形分割トーラス（頂点 $L^2$、辺 $3L^2$、三角形 $2L^2$）の各辺に赤・緑・青の 3 量子ビット（$n=9L^2$）を置く。$Z$ 型：各三角形・各色のプラケット。$X$ 型：各頂点・各色に $S^c_{X;v}=\prod_{e\ni v}X^c_e\prod\mathrm{CZ}^{c',c''}_{e,e'}$（CZ の対は cup 積で決まり、$c$ 以外の 2 色に作用する）。緑の CZ 対の辺と色の対応は cup 積の定義に従う（格納上の色の並びだけで判断しない）。$L=3$ で演算子として非可換な対は 27、フラックスのない部分空間で非可換な対は 0 である。

### 2.3 非可換性と CZ 型の残差

$S_A=X^{s_A}(-1)^{q_A(a)}$ と書くと $S_AS_B=S_BS_A(-1)^{\Delta_{AB}(a)}$、$\Delta_{AB}(a)=q_A(a+s_B)+q_A(a)+q_B(a+s_A)+q_B(a)$ はフラックスの線形結合である。持続するフラックスは対応する検査を繰り返しランダムにする。さらに、誤りと補正が閉じた $X$ ループが dressed 安定化子の積ではなく bare な $X$ 星の積になると、状態に CZ 型の残差（非自明な対角 Clifford 誤り）が残り、フラックスが無くても別の色の dressed 測定の結果をランダムにする。生成元が現在可換であることと、現在の状態で測定が決定的であることは別である。

### 2.4 平面パッチと code switching（研究 2・3）

[KZH] Fig. 4 の三角形状の平面パッチ（境界 $\mathcal L_r$, $\mathcal L_b$, $\mathcal L_{rb}$）で、赤・青の 2 層が FSC を作る。手順：(1) FSC を論理 $|+\rangle$、緑を $|0\rangle$ に準備、(2) $\mathbb D_4$ の全安定化子を $O(d)$ ラウンド測定しフラックスを JIT で補正、(3) $U=WV$（$V=\prod\mathrm{CNOT}(r\to g)\mathrm{CNOT}(b\to g)$、$W$ は CS・CS$^\dagger$・境界の $T^\dagger$）で論理 $T^\dagger$、(4) 緑を $Z$ 基底で測り、結果に応じて $S^g_X$ の CZ 部分を作用させて FSC に戻し、$O(d)$ ラウンドの誤り訂正。出力は $T^\dagger|+\rangle$。境界で単一の $Z$ で固定される量子ビットは理想的に固定したものとして除く（縮約モデル）。研究 2 の格子と研究 3 の格子は、固定した量子ビットを除いて $X$ 生成元（$X$ 台と CZ 対）と $Z$ 検査が $d=2,3,5,7,9$ で一致する。

### 2.5 15-to-1 蒸留

15 個の雑音のある $T$ 状態から誤り検出で 1 個を作り、入力の誤りが独立で確率 $\epsilon$ なら出力誤りの主要項は $35\epsilon^3$。Litinski の 11 tile × 11τ の配置 [GoSC]、225-to-1、$(15\text{-to-}1)_{d_X,d_Z,d_m}$ と 2 段の構成と誤り予算モデル [Lit19]。

## 3. 方法：Clifford-stabilizer simulation の二つの実装

### 3.1 共通の原理

Pauli 誤り $E_P$ が Clifford 因子 $C$ を共役すると $E_PCE_P^\dagger=D_C(E_P)C$ で、ドレッシング $D_C(E_P)$ は Pauli 演算子になる。全てのドレッシングが元の生成元と可換または反可換なら、測定は実効的に可換か反可換で、結果は決定的か一様ランダムになり、Clifford-stabilizer group の更新を Pauli 安定化子群の更新に還元できる [Tak]。標本化の厳密性は、復号器の最適性・耐故障性・漸近閾値の証明とは別のものである。

| | 研究 1 | 研究 2 | 研究 3 |
|---|---|---|---|
| 実装 | twisted frame（$\mathbb D_4$ 符号に特化した厳密表現） | Pauli proxy、operator レベル（[Tak] Algorithm 1, 3, Sec. VI D） | Pauli proxy、回路レベル（[Tak] Algorithm 2） |
| 状態 | 平坦配位のアフィン部分空間 $B$、初期の 3 次の位相に加わる $\mathrm{GF}(2)$ 二次形式 $Q$、$X$ フレーム $x$ | Stim の Pauli 安定化子状態＋誤りフレーム $E=X^x\mathrm{diag}(\omega^{\gamma})$ | Clifford 回路＋前向きに伝播する $X$ 成分とドレッシングの挿入 |
| 照合 | $L=3$ で密な状態ベクトル、$L=3$–9 で Pauli proxy 版と軌道ごとに一致 | C1–C3 を $d=3,5,7$ で検査、$d=2$ 総当たり・$d=3,4$ 独立エンジンと軌道ごとに一致 | 適用条件を $L=2..7,9$ で検査、$L=1,2$ で真の非 Clifford 回路と一致 |

### 3.2 twisted frame（研究 1）

1 ショットの状態を $\psi(a)\propto(-1)^{\phi_0(b)+Q(b)}\mathbf 1[b\in B]$、$a=b+x$ で厳密に保持する。$\phi_0$ は初期符号状態の 3 次の位相、$Q$ は $\phi_0$ に加わる $B$ 上の二次形式で、変化するのは $Q$ だけである。$\phi_0$ は恒等式 $\phi_0(b+s)+\phi_0(b)=q(b)$ により途中で不要。$B$ は垂直方向のホロノミーを 0 に制限した平坦配位の空間の中のアフィン部分空間で、トーラスの全平坦配位ではない。dressed チェックの射影測定は、(i) $s$ が $B$ の方向空間に含まれる：決定的または確率 1/2 で $B$ を超平面に制限、(ii) 含まれない：確率 1/2 で $B\to B\cup(B+s)$ と広げ $Q$ に二次の項を加える（再ランダム化）、の 2 通りである。振幅の比は $b$ と $b+s$ の両方が $B$ に属する点でだけ用い、台が互いに素な場合は (ii) の議論による。全て $\mathrm{GF}(2)$ の行列演算で、費用は系の大きさの多項式である。論理状態は $x$ 方向の 3 色のホロノミーの 8 セクターの重ね合わせで、終了時のセクター表から論理忠実度 $F$ を計算する。

### 3.3 operator レベルの Pauli proxy（研究 2）

誤りと補正の累積 $E=X^x\mathrm{diag}(\omega^{\gamma(a)})$（$\gamma(a)=\sum_il_ia_i+4\sum_{i<j}Q_{ij}a_ia_j\bmod 8$）を古典的に保持し、dressed 生成元 $M=X^s\Delta$ を $E^\dagger ME$ として測る。CZ 因子の Pauli proxy は恒等（dressed 生成元の proxy は bare な $X$ 星）で、得られる Pauli 演算子を Stim で測る。$C=\mathrm{diag}((-1)^{\phi_0})$ として、厳密性の十分条件は (C1) 平坦部分空間上で $CX^{s_G}C^\dagger=G$、(C2) $C$ は FSC の状態に自明に作用、(C3) 平坦部分空間上で $UC=CVT_h$（$U$ の proxy は $V$、論理 $T^\dagger$ は $T_h=\mathrm{diag}(\omega^{7h})$ として帳簿に残す。[KZH] Theorem 2 の点ごとの形）。コードは C1–C3 を各 $d$ のランダムな平坦配位で検査する（実装検査であって全配位の証明ではない。証明にあたるのは C1 が $\phi_0$ の定義から、C3 が [KZH] Theorem 2 から従うことである）。switch-out の緑の測定は分岐反転演算子 $S^g_X(\lambda)$ を $E$ に掛ける（[Tak] Algorithm 3）。論理評価は目標状態の論理 Clifford 安定化子の proxy の期待値による（[Tak] Sec. VI D）。

研究 1 の記憶実験も同じ方式で表せる（物理状態を $E\,C|\mathrm{frame}\rangle$、初期 frame は平坦配位の一様重ね合わせ）。この Pauli proxy 版を相互検証に用いた（§4.3）。

### 3.4 回路レベルの Pauli proxy（研究 3）

1 ショットごとに Pauli 誤りを標本化し、真の回路から対角な第 3 層ゲート $D$（CCZ、CS、CS$^\dagger$、$T^\dagger$）を除いた Clifford 部分を Stim で実行する。誤りと適用した $X$ 補正の $X$ 成分 $e$ を前向きに追跡し、$D$ の位置で $e$ が $D$ の台に乗れば $D$ の代わりにドレッシング $C_e=D^\dagger X^eDX^e$ を挿入する。適用条件（$X$ 因子と CZ 因子の台が素、ドレッシングが単一量子ビット $Z$、群交換子が $Z$ 安定化子の張る空間に入る、primary-support exactness、$U$ と補正が CNOT と対角第 3 層ゲートのみ、出力の論理安定化子が Clifford）を $L=2..7,9$ で確認した。

### 3.5 復号器

* **フラックス**：3 研究とも、新しいフラックスを未来側に開いた時空グラフの最小重み完全マッチング（PyMatching）で実時間に組にし、確定した空間的な補正をその場で適用する（[KZH, Dav] の JIT の考え方。[Dav] の復号器そのものではない）。研究 1 は実事象どうしの組だけを補正し、測定誤りが 0 のときは未来境界を置かない。研究 2 は空間境界つきの平面グラフに一般化し、未来境界と組になった事象への経路の空間部分も補正する。研究 3 は毎ラウンド全履歴を復号し、switch-out の $Z^g$ 読み出しを緑のフラックスと結合する。
* **$U$ をまたぐ復号**：研究 3 はプロトコルの全ラウンドを 1 つの時空グラフで扱う。研究 2 の理想化しない境界でも、$U$ の時点で保留されたフラックスを switch-out の読み出し（緑）と表面符号のラウンド（赤青）と、赤青の電荷を switch-in と表面符号のラウンドと、それぞれ 1 つのグラフで復号する（$Z^r$, $Z^b$ は $U$ とも $S^g_X$ とも可換なので補正を $U$ の後に回せる）。緑の電荷は $U$ の前に後始末し、その残りは $V$ で赤青の電荷の組になる（相関・ハイパーエッジは近似しない）。
* **電荷**：研究 1 は bare な検査の Stim 回路の誤りモデルを事前分布とする時空 MWPM（回路レベルでは実回路の故障表から一次の近似で較正し、$Z$ 対の相関の重み $\kappa_{\rm dec}$ を走査で選ぶ：符号容量型 0.5、現象論的 0、回路レベル 0.1）。研究 3 は Pauli proxy 回路の誤りモデル上の MWPM。

### 3.7 統計

* 研究 1・2 の失敗率は二項の Agresti–Coull 区間（95%）。交点は隣り合うサイズの曲線の log–log 補間で、区間は失敗数を Jeffreys 事後分布から再標本化し、交点が一意に出た標本の分位点とする（交点位置の標本変動を表し、漸近閾値の区間ではない）。
* 研究 3 の各ショットの不忠実度は $X\in\{0,1/2,1\}$ で、件数 $(n_0,n_{1/2},n_1)$ は多項分布に従う。$\hat\varepsilon=(n_1+n_{1/2}/2)/N$、$\mathrm{Var}(\hat\varepsilon)=(p_1+p_{1/2}/4-\varepsilon^2)/N$。（$2S=2n_1+n_{1/2}$ を Poisson とみなすと、不忠実度 1 が主な低誤り率で分散を約半分に見積もる。）データによる判定には、有界な損失 $X\in[0,1]$ に対する Beta(1/2,1/2) 混合の信頼列を用いる：
$$E_N(\mu)=\frac{B(S+\tfrac12,N-S+\tfrac12)}{B(\tfrac12,\tfrac12)\,\mu^S(1-\mu)^{N-S}},\qquad \{\mu: E_N(\mu)<M/\alpha\}.$$
$E_N$ は非負の優マルチンゲールなので、Ville の不等式により任意の停止時刻で有効であり、シミュレーションが失敗数や計算時間で停止し、後から点を追加した場合にも使える。1 つの判定（シナリオ・$p$・窓）で候補になるシミュレーション済みのサイズ全体（$M$ 点、ここでは 4）を Bonferroni で同時に覆い、上端が要求以下なら「データで保証」、下端が要求を超えれば「データで棄却」、その他は「未確定」とする。表全体（最大 200 点）を同時に覆う基準も感度として示す。モデルは多項分布の対数線形モデル（bulk と切り替えの窓の 2 成分）を最尤法で当てはめ、パラメトリック・ブートストラップ（200 回）の 95% 以上が要求を満たすサイズを「モデルの支持」とする。モデルの支持はデータの保証ではなく、実測点の判定を上書きしない。

## 6. 研究 3：code switching と 15-to-1 蒸留の資源比較

### 6.1 問題設定

物理誤り率 $p$ と要求出力誤り $\varepsilon_{\rm target}$ を与えたとき、論理 $T$ 魔法状態（$T^\dagger|+\rangle_L$）1 個に必要な時空間体積（物理量子ビット数 × 時間ステップ数）を、同じ回路レベル雑音の A・B（§3.6）で比べる。全てのゲート・初期化・測定を 1 ステップとする。回転表面符号（較正と蒸留側）の 1 ラウンドは 6 ステップ、Kobayashi 方式の回路の中の FSC のラウンド（S0・S4）はシミュレーションしたスケジュールで 14 ステップである。古典処理の待ち時間、FSC → 通常パッチの変換、状態注入は含めない。

### 6.2 Kobayashi 方式の回路と費用

S0（FSC の準備、$d$ ラウンド）→ S1（緑を $|0\rangle$、$\mathbb D_4$ の全安定化子 $d$ ラウンド、最後に $Z$ だけのラウンド 2 回）→ $U$ → SO（緑の読み出し、復号、補正 CZ の層）→ S4（FSC $d$ ラウンド）→ 評価用の雑音なし 1 ラウンド。$X$ 型安定化子は補助量子ビット 1 個の CNOT と CCZ で測る（パッチは対角線のない正方格子で、内部の検査は CNOT 4 個と CCZ 2 個、境界の検査は例えば CNOT 6 個と CCZ 1 個。研究 1 の三角形分割トーラスの重さ 6 の検査とは異なる）。$\mathbb D_4$ 相の 1 ラウンドは $Z$ 検査 6 ステップ＋$X$ 型 28 ステップ。量子ビット $12d^2+4d-1$、時間 $62d+21$、体積 $632d^3+454d^2+8d-14$（$d=3..11$ で回路から数えた値と一致）。FSC を 8 ステップの並列スケジュールで数えると時間 $50d+21$（費用だけの感度）。フィードフォワードの $X$ 補正は雑音なし・時間 0 の Pauli 層とする。

* データで保証されるのは、B・$p=10^{-4}$・要求 $10^{-4}$ の $d=5$ だけで、$d=3$ はデータで棄却されるので最小サイズも確定する。体積は Litinski 方式の **2.30 倍**。
* 各条件で「データで棄却されない最小のサイズ」の体積を下限とすると、**要求 $10^{-4}$ の全 10 条件**（A・B × $p=10^{-4}$–$10^{-3}$）で Kobayashi 方式の体積は Litinski 方式の **1.59 倍以上**（最小は B・$p=3\times10^{-4}$）。「全 10 条件」は表全体についての主張なので、表全体の基準（$M=200$）でも確かめた：下限サイズは全 10 条件で行ごとの基準と同じで、1.59 倍以上はそのまま成り立つ（v11 で列を追加）。
* 要求 $10^{-6}$ 以下では、シミュレーションした $d\le9$ の多くがデータで棄却される。データで棄却されない最小のサイズ（未計算の $d\ge11$ は棄却されないものとして数える）から体積の下限を作ると、要求 $10^{-6}$ では 10 条件中 9 条件で Litinski 方式の 1.9–10.2 倍以上（残る A・$p=10^{-3}$ は $d\ge11$ からの 0.90 倍）。$d\ge11$ を計算していないので弱い下限であり、要求 $10^{-8}$・$10^{-10}$ ではそれぞれ 3 条件・7 条件で 1 倍を下回り、データだけでは判定できない。（`results_v11/cost_comparison.csv` の `ratio_kobayashi_low_over_litinski`。2026-11-05 の統合論文の執筆時に記述を修正。）
* 表全体（最大 200 点）を同時に 95% で覆う、より厳しい基準では、到達の保証は全 40 条件で未確定である。費用の下限はこの基準でも付き、40 条件中 39 条件で下限サイズは行ごとの基準と同じ（B・$p=3\times10^{-4}$・要求 $10^{-6}$ だけ $d\ge9$ になり、下限は 10.2 倍から 5.6 倍に下がる）。

**モデルによる支持**（保証ではない）：要求 $10^{-4}$ の B・$p=10^{-4}$ と $2\times10^{-4}$ で $d=7$（体積比 6.1 倍、4.2 倍）。要求 $10^{-6}$ 以下では、$d\le61$ のどの条件でもモデルは到達を支持しない。主モデルは窓の成分が $d$ によらないと**仮定**しており、$d$ 依存を許した変種（altW、$d\ge5$ に当てはめ）でも支持は出ない。どちらも $d\le9$ に当てはめた記述モデルの外挿であり、大きい $d$ での誤りの床を示したものではない。

**結論**：本研究で構成した回路・スケジュール・復号器と比較モデルの範囲では、データで判定できる全ての条件で 15-to-1 蒸留の方が小さい体積で要求を満たし、Kobayashi 方式は要求 $10^{-6}$ 以下に届かない（モデルによる）。最適化された Kobayashi 方式に対する一般的な優劣を示すものではない。

### 6.7 考察

(1) [Tak] の方法で、回路レベル雑音の code switching 全体（$d=9$ で 1,007 量子ビット）を厳密に標本化できた。(2) 回路の選択が窓の誤りの大きさを左右する：$U$ 直前の $Z$ ラウンドの数で単一故障の寄与が約 1/10 になった。一方、同じ選択は現象論的雑音の研究 2 では誤りを 2–3 倍に増やした（各ラウンドに全量子ビットのデータ雑音が入るため）。窓の設計は雑音モデルとともに最適化する必要がある。(3) Kobayashi 方式が不利な主な理由は、計算した $d\le9$ の範囲で切り替えの窓の誤りが $d$ とともに十分に下がらないこと（より大きい $d$ での振る舞いは未確定）、$\mathbb D_4$ 相の $X$ 型ラウンドが長いこと（体積 $\approx632d^3$）、アイドル雑音があると待ち時間の雑音が大きいことである。(4) 結論を変えうる要因：窓の誤りを除く復号・回路（[Dav] の JIT 復号器、CCZ ガジェットの flag 化、ハイパーエッジを扱う復号器）、CCZ の実際の誤り率、未計上の費用、Litinski 側の回路レベルのシミュレーション。

## 7. 総合考察

### 7.1 3 研究の関係

3 研究は $\mathbb D_4$ 符号の評価を「符号そのもの」→「code switching のガジェット（現象論的雑音）」→「回路レベル雑音での資源比較」と広げたもので、全て [Tak] の枠組みの中の厳密な標本化である。研究 1 の twisted frame と研究 2・3 の Pauli proxy は同じ記憶実験で $L\le9$ まで軌道ごとに一致し、研究 2 の正当化でも twisted frame 系のエンジンと Pauli proxy が一致した。研究 1 の回路レベル雑音は研究 3 の B と同じ定義である。

### 7.2 数値の比べ方

研究 1 の値はトーラスの記憶実験の、flux 成功に条件付けた電荷側の失敗率の交点、研究 2 の値は境界のあるパッチの code switching 全体の「目標状態と一致しない割合」の交点、研究 3 の値は特定の $(d,p)$ での出力不忠実度である。研究 1 の現象論的雑音の交点（約 2.0–2.2%）と研究 2 の ideal の交点（約 2.4–3.0%）は近いが、同じ閾値の二通りの測定とは読めない。

### 7.3 共通の限界

有限サイズ（漸近閾値は未確定）、最適化していない復号器、理想化（研究 1 の初期状態と終了処理、研究 2 の $U$・補正、研究 3 のフィードフォワード、境界の固定量子ビット）、ネイティブ CCZ、特定の論理状態（研究 1 は一方向のホロノミー、研究 2・3 は入力 $|+\rangle$）。

## 8. 結論

1. $\mathbb D_4$ Clifford 階層安定化子符号とその code switching を、[Tak] の枠組みの二つの独立な実装（twisted frame と Pauli proxy）で、非可換性や非 Clifford ゲートを近似せずに多項式時間で標本化し、両者が $L\le9$ まで軌道ごとに一致することを示した。
2. 電荷側の有限サイズ交点は、現象論的雑音で 2.25→2.09→2.00%、符号容量型で 9–10%、回路レベル雑音で約 0.2%（試行値）。完全測定でも CZ 型の残差がランダムな測定結果を生む。
3. code switching の交点は、$U$ の前を理想化すると 2.97%、2.41%、しないと 2.23%、1.94% で、$U$ を挟むことによる誤りの増幅が大きい。
4. 回路レベル雑音の資源比較では、データで判定できる全ての条件で 15-to-1 蒸留の方が小さい体積で要求を満たした（要求 $10^{-4}$ で 1.59 倍以上、保証された唯一の条件で 2.30 倍）。
